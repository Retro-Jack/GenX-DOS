GenX-DOS: ROMs, BIOS and firmware
=================================

This copy of GenX-DOS has every emulator, but not the games we added, or the
system firmware some machines need before they will start. The public site
at https://genx-dos.fun carries the full set. Copies from GitHub and the
release package don't.

Anything an emulator's own maintainer shipped with it, firmware or games, is
still here and needs nothing from you. Everything else is listed below: the
exact file each menu entry looks for, and where it goes, relative to the
folder this file is in. Names must match exactly, including case. If a file
is missing, that entry won't load, and everything else still works.

Where you get these files is up to you. We won't answer questions about
sourcing ROMs, BIOS or firmware, for legal reasons, so please don't ask.

Arcade
------
  These run MAME 2003-Plus, the libretro port of MAME 0.78, so the romsets have
  to be of that era. A set built for a current MAME disagrees with it constantly
  on filenames, and occasionally on which archive a chip belongs in, and the
  core refuses the game rather than guess. Each file below is named after its
  romset, and every one here was built by CRC against the core's own metadata
  (metadata/mame2003-plus.xml in libretro/mame2003-plus-libretro, at commit
  d3ac6c95) and then verified member by member, with no absent, wrong or extra
  file in any of them.

  One of the hundred is a clone set: sitv, the TV version of Space Invaders.
  Its four files are all in the one zip, so the parent set is not needed.
