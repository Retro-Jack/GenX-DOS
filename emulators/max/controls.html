Commodore MAX Machine — Controls

VICE x64 (gold-standard Commodore emulator) running in your browser via EmulatorJS, switched into Ultimax mode — that's the MAX Machine: a Japan-only 1982 home console using the same VIC-II + SID + 6510 chipset as the C64, but with only 2 KB of RAM and no built-in BASIC. Every program is a cartridge. Click the canvas first so the emulator receives keyboard input.

The MAX library is small — about 27 commercial cartridges were ever produced, all in Japan in 1982-83. Eight of the most iconic carts are bundled here, plus the MAX BASIC cartridge (which is how you'd boot the MAX into a usable BASIC environment, since the machine ships without BASIC in ROM).

Joystick (numpad)

The joystick is on the numeric keypad (the bundle sets vice_joyport_type='1'). NumLock must be on — the numpad only emits digit codes with NumLock on, and a banner reminds you if it's off. Most MAX carts are joystick-only.

KeyAction
Numpad 8 / 2 / 4 / 6Up / down / left / right
Numpad 0 (or 5)Fire

If a cart ignores the stick, swap the joystick port in the gear menu's core options.

MAX keyboard

The MAX has a membrane key matrix sharing the C64's layout; VICE maps it positionally — letters, numbers and most punctuation type as themselves. The special keys (from the libretro VICE keymap):

KeyMAX key
TabCTRL
L CtrlC= (Commodore key)
Scroll LockRUN/STOP (remapped from Esc — see note below)
Page UpRESTORE
BackspaceINST/DEL
Delete↑ (up-arrow / Pi)

Why Scroll Lock for RUN/STOP? Browsers capture Esc to exit pointer-lock and fullscreen before the libretro keyboard callback can see it, so a real Esc press never reaches VICE. The bundle remaps Scroll Lock via emulators/_shared/genx-vice-softkeys.js — a document-level keydown listener swallows the Scroll Lock press and dispatches a synthetic Escape event (synthetic events don't trigger the browser's Esc-capture since they aren't real user gestures), which then reaches the core as RUN/STOP. Scroll Lock has no other use in this bundle so the remap is free.

Why so few games?

The MAX was Commodore's attempt at an entry-level games console for the Japanese market, launched June 1982 — six months before the C64 reached US shelves. With only 2 KB of usable RAM (less than the VIC-20!) and no BASIC ROM, it was crippled out of the gate; the parallel C64 launch made it instantly redundant. Production stopped within months and Commodore Japan moved on. Only ~27 official cartridges ever shipped — the entire library is smaller than a single year of Commodore 64 releases. The MAX is the rarest mainstream Commodore product.

Cart format: Ultimax-mode 8K cartridges mapped to $E000 (and 16K split $8000 + $E000). VICE accepts these as standard .crt files with hardware type 0, EXROM=1, GAME=0. Emulator: VICE x64 (GPL-2.0, libretro core) under EmulatorJS (GPL-3.0). Both shipped locally from this site; no network calls at runtime.
