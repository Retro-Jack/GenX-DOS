Apple · I (1976, MOS 6502, 4 KB RAM, Woz Monitor in ROM)

Apple I — Controls

Will Scullin's Apple I emulator (MIT) running as plain JavaScript — no WASM. Steve Wozniak's first commercial machine: a 6502 at ~1 MHz, 4 KB of RAM, the Woz Monitor in ROM, and a 40×24 character display refreshed at glacial pace (one character per frame). No BASIC built in — any language ships as a cassette tape. Click the screen first so the emulator receives keyboard input.

Keyboard

The real Apple I had an ASCII keyboard that produced uppercase letters and a tiny set of control codes. The emulator maps:

Modern keyApple I key
Letters / digits / punctuationType as uppercase (real Apple I had no lowercase)
EnterRETURN / carriage return (CR)
BackspaceRubout — Woz Monitor and Integer BASIC treat backspace as a line-edit delete
EscESC — used as an escape/break in some tape programs
Ctrl+LClear screen (CLEAR SCREEN key on the original)
TabTAB (not standard on the real machine, mapped for convenience)
RESET button (in the UI)CPU reset — jumps to $FF00 (Woz Monitor entry)

Loading a tape

From the prompt entry (Woz Monitor), the corner gear exposes the bundled cassette library. Each menu game already auto-selects its tape via the ?tape=<key> URL — but you can also load tapes by hand:

  1. Open the emulator menu (top-right of the canvas).
  2. Pick "Tapes" / "Input Tape", choose a program from the dropdown.
  3. In Woz Monitor, type the entry-point address followed by R (e.g. E000R for Integer BASIC) once the tape finishes loading.

The bundled tape library includes 10 games (auto-launched by the menu) plus four system tapes: Integer BASIC (Wozniak's original, entry E000R), Applesoft Lite (a stripped Applesoft port that fits Apple I memory), Woz Monitor source (the ROM listing as a tape), and VolksForth (a Forth implementation).

Woz Monitor commands

The default prompt is a single \ (backslash). Woz Monitor's entire command set:

SyntaxEffect
XXXXDisplay the byte at hex address XXXX
XXXX.YYYYDisplay the range XXXX to YYYY in 8-byte rows
.YYYYContinue the previous range up to YYYY
XXXX: DD DD DD …Write byte values starting at XXXX
: DD DD DD …Continue writing after the last stored byte
XXXXRRun (jump to) hex address XXXX — e.g. E000R to enter Integer BASIC after loading the tape

That's the whole language. Six characters of source for the entire OS, in 256 bytes of ROM.

Integer BASIC commands

Once Integer BASIC is loaded (E000R), the prompt changes to >. Integer-only — no floating point.
