Amstrad · CPC 6128

Amstrad CPC — Controls

floooh's tiny8bit CPC emulator (Andre Weissflog) running as a standalone WASM build. The CPC 6128 (128 KB RAM, BASIC 1.1, 3-inch floppy drive) was released 1984 by Amstrad as the UK / European rival to the C64 and Spectrum — the CPC range sold ~3 million units and built one of the strongest 8-bit game libraries outside Japan. Click the canvas first so the emulator receives keyboard input.

Game launch

Pick a game from the menu and it autoboots — no catalog screen, no run"… typing. Each game's games.json entry carries the boot command (e.g. run"ontherun for Roland), which tiny8bit's sokol_args reads as URL params and types into the emulator immediately after the disk mounts.

The BASIC menu entry skips the autoboot — you land at the bare Locomotive BASIC 1.1 Ready prompt as if no disk were inserted.

Joystick (mapped to keyboard)

Most CPC games support joystick input on the dedicated 9-pin port. tiny8bit maps this to the cursor keys with Space as fire:

KeyAction
↑ ↓ ← →Joystick directions
SpaceFire
PgUp / PgDnFire (alternate — also wired to Space for hands that prefer them)

tiny8bit's chips library only wires one fire button; Space is the canonical key. Our play.html adds a capture-phase listener that remaps PgUp / PgDn to dispatch as Space, so either side of a numeric keypad can fire.

CPC keyboard (for games that need typing)

The CPC keyboard is mapped positionally: letters / digits type as themselves. CPC-specific keys:

KeyCPC key
EnterRETURN
EscESC (often "pause" or "quit" in-game)
BackspaceDEL
TabTAB

BASIC prompt — common commands

From the BASIC menu entry (or if a game drops you back to Ready), these are the period-correct disc commands:

CommandEffect
catList the disk's directory
run"<name>Run a specific program by filename (use what cat shows)
load"<name>Load a BASIC program without running it

CPC convention: the closing quote on run"name is optional — Locomotive BASIC closes it for you at the line end.

Reset

tiny8bit has no toolbar — to cold-reset the emulator, reload the page in your browser (F5 / Ctrl+R). The bundled disk re-mounts and the game re-autoboots.

Emulator: tiny8bit CPC (MIT, by Andre Weissflog — floooh/chips-test). Three prior cores were tried and dropped: EmulatorJS + Caprice32 (cap32) aborts during disk attach with a missing getControllerPortInfo export; CrocoDS boots but stops at a catalog menu with no API to skip; cpcbox is minified beyond editing and rejects our .dsk images. tiny8bit was the fourth attempt — clean URL-param config, no EJS dependency, drop-in autoboot via the input field. Shipped locally; no network calls at runtime.
