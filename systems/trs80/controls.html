Tandy · TRS-80 Model I (Level II BASIC)

TRS-80 Model I — Controls

A Radio Shack TRS-80 Model I with 48 KB and Level II BASIC, running on the sdltrs emulator. Each menu entry loads a self-contained .cmd arcade game and jumps straight into it — there's no CLOAD or disk step.

Keyboard

The Model I's keyboard maps directly to your PC keyboard for letters, numbers and punctuation. The keys that differ from a modern layout:

PC keyTRS-80 key
Home or DeleteCLEAR — most arcade games start with it (see the CLEAR button below)
EscBREAK — interrupts a running program / returns to BASIC
↑ ↓ ← →TRS-80 arrow keys (movement in most games)
Shift + ↓@ / cursor-down on the original keyboard
EnterENTER
ShiftSHIFT (the Model I has no lower-case without the mod, so text is upper-case)

Playing the games

Almost every Big Five Software / Adventure International title in this collection follows the same pattern:

KeyAction
← → (and ↑ ↓)Move / steer
SpaceFire
CLEAR (Home)Start play from the title screen
EscBREAK — abort back to the BASIC READY prompt

Each game also prints its own key list on its title or instruction screen — check there for the exact rotate / thrust / smart-bomb keys, then press CLEAR to begin. The per-game pages (the controls link on each game) spell these out.

The CLEAR button

A labelled CLEAR button sits in the top-left corner. It sends the TRS-80 CLEAR key, which most games use to begin play — handy on laptops and keyboards with no Home key. The keyboard shortcut is Home or Delete.

Mapping follows sdltrs (BSD-2-Clause, Mark Grebe / Jens Guenther). To restart a game, reload the page.
