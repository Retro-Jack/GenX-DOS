TRS-80 Model III — Controls

A Radio Shack TRS-80 Model III with 48 KB, running in your browser. The Model III runs the Model I library, so these are the same arcade titles on the tidier, faster machine — one box instead of three, a 2.03 MHz Z80 instead of 1.77, and a keyboard with a numeric keypad. Each menu entry loads a self-contained .cmd arcade game and jumps straight into it — there's no CLOAD or disk step.

Keyboard

The Model III's keyboard maps directly to your PC keyboard for letters, numbers and punctuation. The keys that differ from a modern layout:

PC keyTRS-80 key
Home or DeleteCLEAR — used by several games (to begin play, or in-play — some use it for hyperspace). See the CLEAR button below.
EscBREAK — interrupts a running program / returns to BASIC
↑ ↓ ← →TRS-80 arrow keys (movement in many games — but several use letter keys instead)
Shift + ↓@ / cursor-down on the original keyboard
EnterENTER
ShiftSHIFT (the Model III has lower-case as standard, unlike the Model I)

Playing the games

Controls vary from game to game — these are arcade titles from several authors, each with its own scheme (some steer on the arrow keys, others on letter keys, and each game's own page has its verified layout). The common threads across the set:

KeyTypical use
arrow keys or letter keysMove / steer (depends on the game)
SpaceFire (most of the shooters)
EnterSecond weapon / smart bomb on some games
CLEAR (Home)Begins play on several games (and is hyperspace in a few)
EscBREAK — abort back to the BASIC READY prompt

Each game prints its own key list on its title or instruction screen — and the per-game controls link on each game spells out the verified scheme for that title.

The CLEAR button

A labelled CLEAR button sits under the machine, in front of the keyboard. It sends the TRS-80 CLEAR key, which several games use (to begin play, or in-game) — handy on laptops and keyboards with no Home key. The keyboard shortcut is Home or Delete.

Mapping follows sdltrs (BSD-2-Clause, Mark Grebe / Jens Guenther). To restart a game, reload the page.
