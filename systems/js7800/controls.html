Atari 7800 — Controls

The 7800's ProLine joystick has two action buttons. Player 1 is on the keyboard out of the box; the console switches sit on Enter / Shift.

Player 1 joystick

KeyAction
↑ ↓ ← →D-pad
ZLeft fire (Button 1)
XRight fire (Button 2)

Console switches

KeyAction
EnterReset switch — starts the game from the title screen
ShiftSelect switch (cycles game variations on many titles)
PPause switch

PAUSE, SELECT and RESET are also keys under the set — the only switches the 7800's case carried.

Notes

Most 7800 carts open on a title screen — press Enter (Reset) to start play; on many titles Shift (Select) cycles the difficulty/variation first.

A USB gamepad works automatically — Player 1 is auto-mapped to the default scheme above.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Runs on EmulatorJS with the ProSystem libretro core (GPL-2.0). Keys are fixed to the defaults above.
