Handheld · Sega Game Gear (1990)

Sega Game Gear — Controls

The Game Gear, running in your browser. Sega's colour answer to the Game Boy — a backlit screen and a slew of Master System and arcade conversions. Click the game area to enable sound and controls.

Controls

D-pad on the arrows, the two face buttons (1 and 2) on Z / X, Start on Enter:

KeyGame Gear
↑ ↓ ← →D-pad
ZButton 1
XButton 2
EnterSTART

Most games use Button 1 / Button 2 as jump & attack (or the reverse) — each game's notes spell out which is which.

A USB gamepad works automatically. The D-pad is the pad, B is Button 1 and A is Button 2, with Start on Start.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Cartridge saves (battery RAM, e.g. Defenders of Oasis) persist in the browser between sessions; the Save/Load menus are a separate snapshot system with five slots.
