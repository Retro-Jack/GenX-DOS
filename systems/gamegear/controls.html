Handheld · Sega Game Gear (1990)

Sega Game Gear — Controls

The Game Gear runs on genesis_plus_gx (the accuracy-focused Sega libretro core) via EmulatorJS. Sega's colour answer to the Game Boy — a backlit screen and a slew of Master System and arcade conversions. Click the screen first so the emulator takes keyboard input.

Controls

D-pad on the arrows, the two face buttons (1 and 2) on Z / X, Start on Enter:

KeyGame Gear
↑ ↓ ← →D-pad
ZButton 1
XButton 2
EnterSTART

Most games use Button 1 / Button 2 as jump & attack (or the reverse) — each game's notes spell out which is which.

Cartridge saves (battery RAM, e.g. Defenders of Oasis) persist in the browser between sessions; the Save State buttons are a separate, instant snapshot.

Emulator: genesis_plus_gx (libretro core) under EmulatorJS (GPL-3.0). Both shipped locally from this site; no network calls at runtime.
