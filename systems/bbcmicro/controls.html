BBC Micro — Controls

A 1981 Acorn BBC Micro Model B with disc drive. For a clean BASIC > prompt, drop the ?autoboot param from the URL.

Joystick (analogue)

The BBC's analogue joystick is mapped to mouse motion + a button — point the canvas mouse to deflect, click to fire. Many games also accept Z / X / : / / + Return as the keyboard fallback — in this emulator the BBC *: key is your PC apostrophe ' (and ? is /). For a literal * — the start of *CAT, *RUN and every other BBC command — press Shift+', since on the BBC keyboard * is the shifted form of that key.

USB gamepad

A USB gamepad's D-pad drives the standard Z / X / ' / / steering keys directly — this emulator maps the pad to them — so any game using that common scheme (Snapper and many others) plays on the pad with nothing to set up. Games with their own key layouts still use the keyboard.

Sideways menu

This emulator has a top toolbar with disc swap, model select (Model A/B/Master 128), and a "soft reset" button. Hover the top edge to reveal it.

Notes

If a disc starts at the BASIC > prompt instead of running the game, type *EXEC !BOOT and press Return.

Tape-based titles use CHAIN "" to auto-load the next program from cassette.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

The full key reference, including the on-screen BBC keyboard, lives in this emulator's own documentation. Shipped locally from this site; no network calls at runtime.
