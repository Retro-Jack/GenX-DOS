TI-99/4A controls

Running TI BASIC and Solid State Software carts. The 4A's keyboard has shifted control keys via Function (FCTN) and Alpha-Lock; this emulator maps PC modifiers to keep typing natural.

When you boot with no cart you land on the TI title screen — press 1 or Enter for TI BASIC, then the > prompt accepts BASIC commands. With a cart inserted the title screen offers the cart name as option 2; press 2 (or the screen-listed key) to start.

Keyboard mapping

PC keyboard → TI-99/4A. The emulator maps the modifier keys to the closest TI equivalents.

Joystick (joypad emulation)

Most cart games use the TI joystick. The emulator maps the keyboard arrow cluster to joystick 1 fire input — if a game uses joystick 2, watch its on-screen prompts.

TI BASIC tips

  • Lines start with line numbers. Type 10 PRINT "HI", hit Enter, then RUN.
  • SAVE / OLD need a device prefix on real hardware; in the emulator without disk drive, your code lives in RAM only.
  • FCTN+= (Alt+=) issues a QUIT/RESET back to the title screen.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.
