Tandy · Color Computer (CoCo)

Tandy CoCo — Controls

A Tandy/Radio Shack Color Computer 1/2 with Color BASIC. The bundled menu boots cartridges; the Color BASIC OK prompt is one menu entry away.

Keyboard

The CoCo's 53-key keyboard maps directly to your PC keyboard for letters, numbers and most punctuation. CoCo-specific keys:

KeyCoCo key
EnterENTER
Backspace← (BACK / left-arrow, used to delete)
↑ ↓ ← →CoCo arrow keys (also used for in-game movement)
Shift + 0BREAK (interrupt running program)
F1Emulator runtime menu (machine + cart + tape config)

Joysticks

The CoCo has two analogue joystick ports, and several of these games are joystick-only — they ignore the keyboard entirely and will not start without one. Those games get a joystick wired up automatically; the rest are played on the keyboard.

USB gamepad

Plug in a pad, click the game area, then press one of the pad's buttons — browsers hide gamepads until a button is pressed, so nothing happens until that first press. A short note appears on screen once the pad is connected.

The order matters in some browsers. Chrome will only reveal a gamepad to a page that currently has focus, so if the pad is not picked up, click the game area and press a pad button again. Firefox has no such requirement.

The CoCo's joystick had a single button, so A is the one that matters. X and Y do nothing.

Notes

Cart games typically auto-launch from the cart slot — there's no CLOAD step. Tape games (rare in this build) need CLOAD + RUN from BASIC.

Dungeons of Daggorath uses keys + Shift-modifiers heavily — see its bundled docs at colorcomputerarchive.com for the full key chart.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

This emulator's own documentation lists every key and switch. Shipped locally from this site; no network calls at runtime.
