Acorn Electron — Controls

The Acorn Electron (1983), running in your browser. Games load from UEF snapshot files and start immediately.

Keyboard mapping

Most keys map directly. A few special keys:

KeyElectron key
AltFUNC (orange key) — use for function-key combos, e.g. BBC f7 is Alt+7
HomeCOPY
F12BREAK

USB gamepad

Every bundled game supports a USB gamepad. The pad presses each game's own keys — D-pad or left stick to move, and face buttons for the game's actions. The exact mapping is on each game's controls page; an idle pad sends nothing, so keyboard play is unaffected.

Sound

Sound auto-starts when the game tab opens from the DOS prompt. If you opened the page directly, press any key to wake the audio.

Tips

  • Games load from snapshots — they start instantly, no tape loading wait.
  • If a game freezes, press F12 (BREAK) to reset.

Emulator: ElkJS (© Darren Coles 2013; 6502 core ported from Tom Walker's Elkulator). Shipped locally from this site; no network calls at runtime.
