Atari 400 — Controls

The Atari 400 (1979) — the cartridge-era 8-bit machine, booted here with OS-B. It shares the same emulator and input mapping with the 800XL bundle; only the boot OS differs.

UI

Press F1 to open the emulator's menu. From there you can swap disks (D1: through D8:), toggle BASIC, and change machine settings.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Notes

Some 1980s games auto-launch BASIC programs; if a disk drops you to the READY prompt, type RUN "D:<FILENAME>" to start the program. Filenames are visible via DOS at the BASIC prompt.

The 400 menu boots with OS-B (a 1979-ROM equivalent). The 800XL menu boots with OS-XL (a 1983-ROM equivalent). Same keyboard for both.

Mapping follows atari800 v5.2.0 (GPL-2.0+, atari800/atari800). Built to WASM via emscripten with AltirraOS baked in. The full key reference (including international keyboards) lives in the upstream DOC/USAGE.
