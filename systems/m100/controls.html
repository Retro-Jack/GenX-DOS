TRS-80 Model 100 — Controls

A Radio Shack TRS-80 Model 100 — the 1983 portable with a full-travel keyboard, a 240 × 64 monochrome LCD and Microsoft BASIC in ROM — running in your browser. Each menu entry loads a single Model 100 program into the machine's RAM and starts it automatically; there's no cassette or wait. The bare "Model 100" entry boots the machine with nothing loaded, straight to its own menu.

Keyboard

The Model 100's keyboard maps straight onto your PC's — letters, numbers and punctuation (the machine composes its own shifted characters, so you just type), and the obvious special keys are right where you'd expect: Enter, Shift, Ctrl, Tab, Esc, Backspace, the arrow keys and F1–F8. Only two Model 100 keys sit somewhere non-obvious:

The built-in applications

Choose the bare Startup Menu entry and you get the Model 100 as it shipped — its own menu of ROM applications. Move the cursor with the arrow keys, press ENTER to launch one, and F8 (labelled Menu) to come back. Press LABEL to show the current function-key definitions along the bottom line, and SHIFT+Pause/Break to cancel an operation.

TEXT is the word processor. Selecting it asks "File to edit?" — type a name (up to six letters) and press ENTER to create a document called <name>.DO, then type away. Its function keys:

KeyAction in TEXT
F1 FindType a string; the cursor jumps to the first match
F7 SelMark the start of a selection, then move the cursor to extend it
F5 Copy · F6 CutCopy or cut the selection; the PASTE key inserts it back
F2 Load · F3 SaveCassette load / save — no effect in the browser
F8 MenuSave the document and return to the main menu

ADDRSS (address book) and SCHEDL (scheduler) are finders, not editors — you type the data in TEXT, then they search it:

  1. Enter the records in TEXT. Name the file ADRS for the address book or NOTE for the scheduler. Each record is one entry — a name, phone and address; or a date, time and note — and you press ENTER to end each one, then F8 to save and exit.
  2. Then find them. Open ADDRSS or SCHEDL, press F1 Find, type any word from an entry and press ENTER — every matching record appears (page through with the More / Quit keys if there are several). F5 prints the results instead, and F8 returns to the menu.

Record format: there's barely any — one record per line (press ENTER to end each), and the pieces within it can be in any order, because Find simply matches any text in the line. Just make sure whatever you'll search on — a surname, a date — is somewhere in the entry.

FileExample record (one line)
ADRS (ADDRSS)Flintstone, Fred   555 2468   301 Cobblestone Way, Bedrock
NOTE (SCHEDL)Fri 18:00   Bowling night with Barney

Finding Flintstone or Barney then pulls the whole record up.

Saving your work & managing files

The main menu is your filing cabinet — every document and program you make shows up on it. Move the cursor with the arrow keys and press ENTER to open any of them (or the built-in apps). The menu has no file keys of its own; you save, load and delete through BASIC and TEXT:

Command / keyWhat it does
BASIC · SAVE"NAME"Save the current BASIC program as NAME.BA — it appears on the menu
BASIC · LOAD"NAME" · RUN"NAME"Load a saved program back, or load and run it in one go
BASIC · FILESList everything currently stored
BASIC · KILL"NAME.DO"Delete a file — give the full name and extension in quotes (.DO for documents, .BA for programs)
TEXT · F8 MenuSaves the open document to memory and returns to the menu

One gotcha worth knowing: the Model 100 stores file names in upper case, and KILL matches them exactly — so type the name in capitals (tap Caps Lock first), or you'll get a "file not found" (FF) error even though the file's right there on the menu.

The Load and Save function keys in TEXT — and BASIC's CLOAD / CSAVE — drive a cassette recorder, which the browser has no equivalent for, so they do nothing here. You don't need them: F8 and SAVE keep your work in memory, and on the Startup Menu the battery backup below carries it between sessions.

The Startup Menu has battery backup. Like the real Model 100's battery-backed RAM, whatever you create here — documents in TEXT, address-book and scheduler entries, a BASIC program you type in — is saved and comes back the next time you open it. But it's entirely browser-contingent: it lives in this browser's local storage on this device, so it survives a refresh or reopening the page, yet it's gone if you clear your browsing data, it won't follow you to another browser or computer, and in a private / incognito window it only lasts until you close that window. The games are the exception — each one launches fresh every time.

Per-game controls are on each game's own page. Click a game in the menu and the corner controls link takes you to it.
