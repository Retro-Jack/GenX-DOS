Commodore · MAX Machine

Commodore MAX Machine — Controls

The MAX Machine in your browser — a Japan-only 1982 home console using the same VIC-II + SID + 6510 chipset as the C64, but with only 2 KB of RAM and no built-in BASIC. Every program is a cartridge. Click the game area to enable sound and controls.

The MAX library is small — about 27 commercial cartridges were ever produced, all in Japan in 1982-83. Eight of the most iconic carts are bundled here, plus the MAX BASIC cartridge (which is how you'd boot the MAX into a usable BASIC environment, since the machine ships without BASIC in ROM).

Joystick (numpad)

The joystick is on the numeric keypad (the bundle sets vice_joyport_type='1'). NumLock must be on — the numpad only emits digit codes with NumLock on, and a banner reminds you if it's off. Most MAX carts are joystick-only.

KeyAction
Numpad 8 / 2 / 4 / 6Up / down / left / right
Numpad 0 (or 5)Fire

If a cart ignores the stick, it's reading the other joystick port; each cart is preset to the port it expects.

MAX keyboard

The MAX has a membrane key matrix sharing the C64's layout; this emulator maps it positionally — letters, numbers and most punctuation type as themselves. The special keys (from this emulator's keymap):

Why Scroll Lock for RUN/STOP? Browsers capture Esc to exit pointer-lock and fullscreen before the emulator's keyboard callback can see it, so a real Esc press never reaches the emulator. The bundle remaps Scroll Lock with a small shared script — a document-level keydown listener swallows the Scroll Lock press and dispatches a synthetic Esc event (synthetic events don't trigger the browser's Esc-capture since they aren't real user gestures), which then reaches the emulator as RUN/STOP. Scroll Lock has no other use in this bundle so the remap is free.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Why so few games?

The MAX was Commodore's attempt at an entry-level games console for the Japanese market, launched June 1982 — six months before the C64 reached US shelves. With only 2 KB of usable RAM (less than the VIC-20!) and no BASIC ROM, it was crippled out of the gate; the parallel C64 launch made it instantly redundant. Production stopped within months and Commodore Japan moved on. Only ~27 official cartridges ever shipped — the entire library is smaller than a single year of Commodore 64 releases. The MAX is the rarest mainstream Commodore product.

Cart format: Ultimax-mode 8K cartridges mapped to $E000 (and 16K split $8000 + $E000). This emulator accepts these as standard .crt files with hardware type 0, EXROM=1, GAME=0. Shipped locally from this site; no network calls at runtime.
