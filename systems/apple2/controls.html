Apple · ][+ (48K, Applesoft BASIC, Disk II)

Apple ][ — Controls

The Apple ][+ running in your browser — 48 KB RAM, Applesoft BASIC in ROM, and a Disk II controller in slot 6. Each menu entry boots the chosen 5.25" disk image directly; the "Applesoft BASIC" entry boots with no disk inserted, which is what a real ][+ does — it drops to the ] prompt. Click the game area to enable sound and controls.

Keyboard

The Apple ][+ keyboard had no lowercase, no arrow keys other than ← →, and a tiny set of modifiers. This emulator maps:

Modern keyApple ][+ key
← →Cursor left/right (the only two arrows on a real ][+)
↑ ↓Synthesised — used for cursor in apps that read them
EscESC (BASIC line edit, app menus)
TabTAB
CtrlCTRL — needed for Ctrl-C (break BASIC), Ctrl-G (bell), Ctrl-Reset
Shift + Ctrl + DeletePower-on reset (cold boot)
F1OPEN APPLE (left ⌘) — fire button 0 in games
F2CLOSED APPLE (right ⌘) — fire button 1 in games

Joystick / gamepad

The Apple ][+ joystick is emulated by mouse position over the canvas (horizontal = paddle 0, vertical = paddle 1). If a USB gamepad is connected, this emulator detects it automatically via the browser Gamepad API — the analogue stick maps to the paddles and buttons map to Open/Closed Apple. Mouse joystick is disabled while a gamepad is active.

Per-game starting hints

Each game's full controls and how to start it are on its own page — open a game from the menu, then click the controls link in the corner.

Useful BASIC commands

Launching Applesoft BASIC from the menu boots with no disk inserted — the ROM waits ~3 seconds at the disk-not-found screen, then drops to the ] prompt. Try 10 PRINT "HELLO": GOTO 10, then RUN.

CommandEffect
LISTShow the current program
RUNRun the current program
NEWClear the program from memory
HOMEClear the screen
CATALOGList files on the disk (DOS 3.3)
PR#6Boot from drive 1 (Disk II in slot 6)
Ctrl+CBreak out of a running program
