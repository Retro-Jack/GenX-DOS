Sega Master System — Controls

The Master System, running in your browser. Sega's 8-bit challenger to the NES — arcade pedigree, a two-button pad, and a Pause button that lived on the console itself. Click the screen first so the emulator takes keyboard input.

Controls

D-pad on the arrows, the two face buttons (1 and 2) on Z / X, and the console's Pause button on Enter:

KeyMaster System
↑ ↓ ← →D-pad
ZButton 1
XButton 2
EnterPAUSE (the button on the console)

The real SMS pad had no Start button — games that say "PUSH START BUTTON" mean Button 1 or 2. Most games use the two buttons as jump & attack (or the reverse) — each game's notes spell out which is which.

USB gamepads work — D-pad or left stick steers, with the two face buttons as Buttons 2 and 1 (A and B on an Xbox-layout pad) and Start as the console's Pause.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Cartridge saves (battery RAM, e.g. Phantasy Star) persist in the browser between sessions; the Save/Load menus are a separate snapshot system with five slots.
