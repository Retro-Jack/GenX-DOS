Commodore · PET 2001

Commodore PET — Controls

This bundle runs in your browser, emulating a PET 2001 (Commodore's first computer, January 1977) with 32 KB RAM and BASIC 2 (the 1979 "Upgrade" ROM). Click the game area to enable sound and controls.

Each game auto-types load"*",8 into BASIC about a second and a half after the page loads, then auto-types run (or sys 768 for machine-code titles) a few seconds later. Watch the boot screen for the typing — that's the auto-start in action, not user keyboard. Once the game is up, all your keystrokes go straight to the PET.

Keyboard

The PET has no joystick port. All games are keyboard-controlled. This emulator maps the PET keyboard symbolically — letters / numbers / punctuation type as themselves. Two PC keys remap:

PC keyPET key
EnterRETURN
BackspaceINST/DEL

Per-game movement keys vary. Most older PET titles use ; ' , . for directional input (near the right hand) or number rows. Space tends to fire / pick up / pause. Read the on-screen instructions when the game boots.

The PET's STOP key isn't mapped to a PC key in this emulator. To break out of a hung BASIC program, refresh the browser tab — boot time is under two seconds, then auto-start re-runs the game.

What the bundle ships

Ten PRG titles from 1977 to 1982, plus the empty stub that drops you at BASIC's READY. prompt. Each game's own page has its background and controls — open a game from the menu, then click the controls link in the corner.

Emulator: Thomas Skibo's pet2001 (BSD-2-Clause). Shipped locally from this site; no network calls at runtime.
