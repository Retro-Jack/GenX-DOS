Commodore PET — Controls

This bundle runs in your browser, emulating a PET 2001 (Commodore's first computer, January 1977) with 32 KB RAM and BASIC 2 (the 1979 "Upgrade" ROM). Click the game area to enable controls. This emulator doesn't play the PET's sound.

Each game auto-types load"*",8 into BASIC about a second and a half after the page loads, then auto-types run a few seconds later. Watch the boot screen for the typing — that's the auto-start in action, not user keyboard. Once the game is up, all your keystrokes go straight to the PET.

Keyboard

The PET has no built-in joystick port, so every game here is played on the keyboard. Letters, numbers and punctuation type as themselves, and two PC keys stand in for PET ones:

PC keyPET key
EnterRETURN
BackspaceINST/DEL

The arcade games — Space!, Space Invaders, Crazy Balloon and Frog — keep a key pressed on the PET for exactly as long as you hold it, and in those games either Shift key works on its own as the PET's SHIFT, which Space! uses to fire. Most of them move with the number keys. The typing games — Star Trek, Adventureland, Lunar Lander and the rest — take keys one press at a time. Each game's page lists its keys.

In a BASIC game that asks a question and waits for Return, type an answer first: on the PET, Return on its own can stop the program at READY. If that happens, type RUN and press Return.

The PET's STOP key isn't mapped to a PC key in this emulator. To break out of a hung BASIC program, refresh the browser tab — boot time is under two seconds, then auto-start re-runs the game.

What the bundle ships

Ten PRG titles from 1978 to 1982, plus the empty stub that drops you at BASIC's READY. prompt. Each game's own page has its background and controls — open a game from the menu, then click the controls link in the corner.

Shipped locally from this site; no network calls at runtime.
