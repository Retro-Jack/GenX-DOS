Commodore PET — Controls

This bundle runs in your browser, emulating a PET 2001 (Commodore's first computer, January 1977) with 32 KB RAM and BASIC 2 (the 1979 "Upgrade" ROM). Click the game area to enable controls. This emulator doesn't play the PET's sound.

Each game auto-types load"*",8 into BASIC about a second and a half after the page loads, then auto-types run a few seconds later. Watch the boot screen for the typing — that's the auto-start in action, not user keyboard. Once the game is up, all your keystrokes go straight to the PET.

Keyboard

The PET has no built-in joystick port, so every game here is played on the keyboard. Letters, numbers and punctuation type as themselves, and three PC keys stand in for PET ones:

PC keyPET key
EnterRETURN
BackspaceINST/DEL
EscRUN/STOP

The arcade games — Space Invaders, Crazy Balloon, Frog and PETSCII Robots — keep a key pressed on the PET for exactly as long as you hold it, and in those games either Shift key works on its own as the PET's SHIFT. All four move with the number keys. The PET has its own < and > keys; in these games type them as usual, with Shift and , or .. The typing games — Star Trek, Adventureland, Lunar Lander and the rest — take keys one press at a time. Each game's page lists its keys.

In a BASIC game that asks a question and waits for Return, type an answer first: on the PET, Return on its own can stop the program at READY. If that happens, type RUN and press Return.

To break into a BASIC program, press Esc (RUN/STOP): the PET stops at BREAK and READY., and RUN starts the program again from the top. Refreshing the browser tab also restarts the game.

What the bundle ships

Nine PRG titles from 1978 to 1982, PETSCII Robots (2021) on its own disk, and the empty stub that drops you at BASIC's READY. prompt. Each game's own page has its background and controls — open a game from the menu, then click the controls link in the corner.

Shipped locally from this site; no network calls at runtime.
