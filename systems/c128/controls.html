Commodore 128 — Controls

The Commodore 128 in your browser, configured in native mode (BASIC 7.0, 128 KB RAM, dual VIC-IIe + VDC video chips, 8502 + Z80 CPUs). The 128 famously had three personalities: this bundle skips C64 compatibility mode (we have a dedicated C64 bundle for that) and skips CP/M mode, focusing on the 128's distinctive native features. Click the game area to enable sound and controls.

Each game's games.json entry sets the right video chip up-front — VIC-IIe (40 columns, same as the C64) for action games and VDC (80 columns) for the 80-column titles (Star Fleet I, Uniquest, Invaders and the other VDC homebrews) that need the wider display. You can manually swap chips at any time by pressing F7 (the C128's "40/80 DISPLAY" toggle key).

On first load, click the game area to enable sound and controls — the C128 KERNAL takes ~2 seconds to boot (RAM test, dual-video init, BASIC 7.0 setup) and the browser's audio context can't start without a user gesture, so the boot stays frozen on whatever frame it reached until you click. After that single click, boot proceeds normally and finishes at the READY. prompt.

Every bundled game is a single-disk (or single-file) title — no mid-session disk swaps required. (Trinity and Beyond Zork were on the shortlist but their C128 80-column releases ship as dual-sided 1571 D71 images that prompt for disk B mid-game, so single-disk titles were chosen instead.)

The C128's native-mode-only keys (40/80 DISPLAY, ESC, HELP, NO SCROLL, the numeric keypad) aren't on this positional table and aren't mapped to PC keys, so a program that needs one of them can't currently use it.

Why Scroll Lock for RUN/STOP? Browsers capture Esc to exit pointer-lock and fullscreen before the emulator's keyboard callback can see it, so a real Esc press never reaches the emulator. The bundle remaps Scroll Lock with a small shared script — a document-level keydown listener swallows the Scroll Lock press and dispatches a synthetic Esc event (synthetic events don't trigger the browser's Esc-capture since they aren't real user gestures), which then reaches the emulator as RUN/STOP. Scroll Lock has no other use in this bundle so the remap is free.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Why the C128 library is small

The C128 sold ~5 million units but its native mode (BASIC 7.0, 80-column VDC, 2 MHz fast mode) was used by only ~100-200 commercial titles total — most developers targeted the C64 install base and shipped C64-compatible code that ran on the 128 via GO64. The native-mode library is dominated by productivity software (Paperback Writer 128, GEOS 128, Big Blue Reader), with games a rarity — the 80-column titles bundled here are mostly homebrew. Of the commercial action games, only a handful (The Last V8, Rocky Horror Show, Thai Boxing, Kikstart 2) used the 128's native mode meaningfully.
