Amstrad · CPC 6128

Amstrad CPC — Controls

The Amstrad CPC 6128 (128 KB RAM, BASIC 1.1, 3-inch floppy drive), running in your browser. Released 1984 by Amstrad as the UK / European rival to the C64 and Spectrum — the CPC range sold ~3 million units and built one of the strongest 8-bit game libraries outside Japan. Click the game area to enable sound and controls.

Controls — host keyboard → CPC keyboard

Your keypresses arrive as the CPC's own keys, and most of these titles are meant to be played that way: pick the game's keyboard option (or set its redefinable keys to suit). For games with a joystick option, the bundle can emulate the 9-pin port — the cursor keys and Space drive it, and a USB gamepad works too (D-pad or left stick, any face button fires); each game's notes say when that applies. Letters and digits type as themselves; the movement / action keys map like this:

KeyCPC key
↑ ↓ ← →CPC cursor keys (movement in most games)
SpaceSPACE — the usual fire / action key
PgUp / PgDnFire — remapped to Space (handy on keyboards where Space is awkward)
EnterRETURN
ShiftSHIFT
EscESC — Shift+Esc sends BREAK (stops a running program)
BackspaceDEL — Shift+Backspace clears the screen
F1–F10CPC numeric-keypad keys (f0–f9) — some games read these

Space is the canonical fire key; our play.html adds a capture-phase listener that remaps PgUp / PgDn to dispatch as Space too. Note that some browsers intercept F1 (help) before the emulator sees it — if a game wants the keypad, the others (F2–F10) are safer.

BASIC prompt — common commands

The BASIC menu entry loads no game — you land at the bare Locomotive BASIC 1.1 Ready prompt as if no disk were inserted. From there (or if a game drops you back to Ready), these are the period-correct disc commands:

CommandEffect
catList the disk's directory
run"<name>Run a specific program by filename (use what cat shows)
load"<name>Load a BASIC program without running it

CPC convention: the closing quote on run"name is optional — Locomotive BASIC closes it for you at the line end.

Save / load state

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Reset

This emulator has no toolbar — to cold-reset it, reload the page in your browser (F5 / Ctrl+R). The bundled disk re-mounts and the game restarts.

Emulator: tiny8bit CPC (MIT, by Andre Weissflog — floooh/chips-test). Three prior cores were tried and dropped: EmulatorJS + Caprice32 (cap32) aborts during disk attach with a missing getControllerPortInfo export; CrocoDS boots but stops at a catalog menu with no API to skip; cpcbox is minified beyond editing and rejects our .dsk images. tiny8bit was the fourth attempt — clean URL-param config, no EJS dependency, drop-in auto-boot via the input field.
