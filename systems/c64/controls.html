Commodore 64 — Controls

The Commodore 64, running in your browser. Click the game area to enable sound and controls.

The initial disk load takes around 30 seconds — that's not a freeze, it's the real-time 1541 drive emulation reading the disk over the IEC bus at period-authentic speed. You'll hear the drive chunk and stepper-click the whole way through; the game starts when it falls silent.

Joystick (numpad)

The joystick is on the numeric keypad (the bundle sets vice_joyport_type='1'). NumLock must be on — the numpad only emits digit codes with NumLock on, and a banner reminds you if it's off.

KeyAction
Numpad 8 / 2 / 4 / 6Up / down / left / right
Numpad 0 (or 5)Fire

If a game ignores the stick, it's probably reading the other joystick port; each game in this bundle is preset to the port it expects.

C64 keyboard

This emulator maps the C64 keyboard "positionally" to your PC keyboard — letters, numbers and most punctuation type as themselves. The special keys (from this emulator's keymap):

Why Scroll Lock for RUN/STOP? Browsers capture Esc to exit pointer-lock and fullscreen before the emulator's keyboard callback can see it, so a real Esc press never reaches the emulator. The bundle remaps Scroll Lock with a small shared script — a document-level keydown listener swallows the Scroll Lock press and dispatches a synthetic Esc event (synthetic events don't trigger the browser's Esc-capture since they aren't real user gestures), which then reaches the emulator as RUN/STOP. Scroll Lock has no other use in this bundle so the remap is free.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Loading from BASIC

This emulator auto-LOADs the first program on most disks, but if a game drops you to the READY. prompt, type one of:

CommandEffect
LOAD"$",8List the directory of disk drive 8
LOAD"*",8,1Load + run the first program on the disk
RUNRun the loaded program

Shipped locally from this site; no network calls at runtime.
