Commodore · C16

Commodore 16 — Controls

VICE xplus4 (the C16 / C116 / Plus/4 build of the gold-standard Commodore emulator) running in your browser via EmulatorJS, configured for the C16 in PAL mode. The C16 is the entry-level model in the 264 family — 16 KB of RAM with the same TED chip and 121-colour palette as the Plus/4, but no built-in software. Click the canvas first so the emulator receives keyboard input.

All ten bundled games are single-file .prgs that load instantly via VICE autostart — no disk activity, no waiting. If you LOAD a disk image manually the real-time 1541 emulation will chunk for 20–30 seconds before the game starts; that's authentic, not a freeze.

Joystick (numpad)

The joystick is on the numeric keypad (the bundle sets vice_joyport_type='1'). NumLock must be on — the numpad only emits digit codes with NumLock on, and a banner reminds you if it's off.

KeyAction
Numpad 8 / 2 / 4 / 6Up / down / left / right
Numpad 0 (or 5)Fire

The C16 has two joystick ports (the non-standard 8-pin DIN, incompatible with Atari-style sticks). If a game ignores the stick it's reading the other port — swap it in the gear menu's core options.

C16 keyboard

VICE maps the C16 keyboard "positionally" to your PC keyboard — letters, numbers and most punctuation type as themselves. The special keys (from the libretro VICE keymap):

KeyC16 key
TabCTRL
Scroll LockRUN/STOP (remapped from Esc — see note below)
BackspaceINST/DEL
HomeCLR/HOME
Insert£ (pound)

The C16 is a TED machine: it has no Commodore (C=) key and no RESTORE key, so those C64 mappings don't apply here. Its ESC, HELP and the four function keys are reachable through EmulatorJS's on-screen keyboard (gear menu → keyboard icon).

Why Scroll Lock for RUN/STOP? Browsers capture Esc to exit pointer-lock and fullscreen before the libretro keyboard callback can see it, so a real Esc press never reaches VICE. The bundle remaps Scroll Lock via systems/_shared/genx-vice-softkeys.js — a document-level keydown listener swallows the Scroll Lock press and dispatches a synthetic Escape event (synthetic events don't trigger the browser's Esc-capture since they aren't real user gestures), which then reaches the core as RUN/STOP. Scroll Lock has no other use in this bundle so the remap is free.

Loading from BASIC 3.5

The C16 ships with BASIC 3.5 — the same BASIC as the Plus/4, a big upgrade over the C64's BASIC 2 with full sound/graphics commands. VICE auto-LOADs .prg files, but if you drop to the READY. prompt, type one of:

CommandEffect
DIRECTORYList the disk directory (BASIC 3.5 shortcut — equivalent to LOAD"$",8 on C64)
DLOAD"name"Load a program from disk (BASIC 3.5 shortcut)
RUNRun the loaded program

Free BASIC memory on the C16 is 12,277 bytes — about a quarter of what the Plus/4 gives you. Most C16 games are written in tightly packed machine code to fit.

Emulator: VICE xplus4 (GPL-2.0, libretro core) under EmulatorJS (GPL-3.0). Both shipped locally from this site; no network calls at runtime.
