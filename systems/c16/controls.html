Commodore 16 — Controls

The Commodore 16 in your browser, in PAL mode. The C16 is the entry-level model in the 264 family — 16 KB of RAM with the same TED chip and 121-colour palette as the Plus/4, but no built-in software. Click the game area to enable sound and controls.

All ten bundled games are single-file .prgs that load instantly via the emulator's autostart — no disk activity, no waiting. If you LOAD a disk image manually the real-time 1541 emulation will chunk for 20–30 seconds before the game starts; that's authentic, not a freeze.

Joystick (numpad)

The joystick is on the numeric keypad (the bundle sets vice_joyport_type='1'). NumLock must be on — the numpad only emits digit codes with NumLock on, and a banner reminds you if it's off.

KeyAction
Numpad 8 / 2 / 4 / 6Up / down / left / right
Numpad 0 (or 5)Fire

The C16 has two joystick ports (the non-standard 8-pin DIN, incompatible with Atari-style sticks). If a game ignores the stick it's reading the other port; each game is preset to the port it expects.

C16 keyboard

This emulator maps the C16 keyboard "positionally" to your PC keyboard — letters, numbers and most punctuation type as themselves. The special keys (from this emulator's keymap):

KeyC16 key
TabCTRL
Scroll LockRUN/STOP (remapped from Esc — see note below)
BackspaceINST/DEL
HomeCLR/HOME
Insert£ (pound)

The C16 is a TED machine: it has no Commodore (C=) key and no RESTORE key, so those C64 mappings don't apply here. Its ESC, HELP and the four function keys aren't mapped to PC keys in this build.

Why Scroll Lock for RUN/STOP? Browsers capture Esc to exit pointer-lock and fullscreen before the emulator's keyboard callback can see it, so a real Esc press never reaches the emulator. The bundle remaps Scroll Lock with a small shared script — a document-level keydown listener swallows the Scroll Lock press and dispatches a synthetic Esc event (synthetic events don't trigger the browser's Esc-capture since they aren't real user gestures), which then reaches the emulator as RUN/STOP. Scroll Lock has no other use in this bundle so the remap is free.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Loading from BASIC 3.5

The C16 ships with BASIC 3.5 — the same BASIC as the Plus/4, a big upgrade over the C64's BASIC 2 with full sound/graphics commands. This emulator auto-LOADs .prg files, but if you drop to the READY. prompt, type one of:

CommandEffect
DIRECTORYList the disk directory (BASIC 3.5 shortcut — equivalent to LOAD"$",8 on C64)
DLOAD"name"Load a program from disk (BASIC 3.5 shortcut)
RUNRun the loaded program

Free BASIC memory on the C16 is 12,277 bytes — about a quarter of what the Plus/4 gives you. Most C16 games are written in tightly packed machine code to fit.
