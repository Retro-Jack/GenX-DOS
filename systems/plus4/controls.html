Commodore Plus/4 — Controls

The Commodore Plus/4 in your browser. The Plus/4 has 64 KB of RAM and the TED chip (combined video + sound) with a 121-colour palette. Click the canvas first so the emulator receives keyboard input.

When a disk game is loading, the initial read takes around 20-30 seconds — that's not a freeze, it's the real-time 1541 drive emulation reading the disk over the IEC bus at period-authentic speed. You'll hear the drive chunk and stepper-click the whole way through; the game starts when it falls silent. Most of the bundled games are single-file .prgs that load instantly without disk activity.

Joystick (numpad)

The joystick is on the numeric keypad (the bundle sets vice_joyport_type='1'). NumLock must be on — the numpad only emits digit codes with NumLock on, and a banner reminds you if it's off.

KeyAction
Numpad 8 / 2 / 4 / 6Up / down / left / right
Numpad 0 (or 5)Fire

The arrow keys also drive the joystick, with L Ctrl as fire — that's the scheme the per-game controls pages use, and it's equivalent to the numpad above.

The Plus/4 has two joystick ports (the non-standard 8-pin DIN, incompatible with Atari-style sticks). If a game ignores the stick it's reading the other port; each game is preset to the port it expects.

Plus/4 keyboard

This emulator maps the Plus/4 keyboard "positionally" to your PC keyboard — letters, numbers and most punctuation type as themselves. The special keys (from the libretro keymap):

KeyPlus/4 key
TabCTRL
Scroll LockRUN/STOP (remapped from Esc — see note below)
BackspaceINST/DEL
HomeCLR/HOME
Insert£ (pound)

The Plus/4 is a TED machine: it has no Commodore (C=) key and no RESTORE key, so those C64 mappings don't apply here. Its ESC, HELP and the four function keys aren't mapped to PC keys in this build.

Why Scroll Lock for RUN/STOP? Browsers capture Esc to exit pointer-lock and fullscreen before the libretro keyboard callback can see it, so a real Esc press never reaches the emulator. The bundle remaps Scroll Lock via systems/_shared/genx-vice-softkeys.js — a document-level keydown listener swallows the Scroll Lock press and dispatches a synthetic Escape event (synthetic events don't trigger the browser's Esc-capture since they aren't real user gestures), which then reaches the core as RUN/STOP. Scroll Lock has no other use in this bundle so the remap is free.

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Loading from BASIC 3.5

The Plus/4 ships with BASIC 3.5 (a big upgrade over C64's BASIC 2 — full sound/graphics commands). This emulator auto-LOADs .prg files and the first program on most disks, but if a game drops you to the READY. prompt, type one of:

CommandEffect
DIRECTORYList the disk directory (Plus/4 BASIC 3.5 shortcut — equivalent to LOAD"$",8 on C64)
DLOAD"name"Load a program from disk (BASIC 3.5 shortcut)
RUNRun the loaded program
