Vectrex — Controls

The Vectrex shipped with one analogue joystick that had four action buttons in a row. PC keyboard maps the joystick directions and the four buttons.

Action buttons (1 / 2 / 3 / 4)

The Vectrex controller's four buttons sat in a horizontal row labelled 1, 2, 3, 4. This emulator maps them to the home-row keys. Across the library the convention is consistent: Button 4 is fire and Button 3 is thrust, with the joystick handling direction or rotation.

Notes

The period-correct plastic overlay is selected automatically per game. To reset or switch games, use the GenX-DOS menu or reload the page.

The Vectrex's BIOS plays the "Vectrex" intro tune at every boot — wait it out (about 4 seconds) before pressing buttons.

Most cartridges have no in-game pause.

USB gamepads work — and here the analogue stick is the point. Most machines on this site are digital, so their pages tell you to use the D-pad. The Vectrex is the exception: its controller was genuinely analogue in 1982, and the left stick drives those same axes, so how far you push it matters and not merely which way. The four face buttons are the Vectrex's four, in row order — X is button 1, Y is 2, A is 3, B is 4. The D-pad only stands in on a pad with no stick at all.

The Vectrex has no pause: the machine simply has no such control, so almost no cartridge offers one. Resetting or reloading is the only way out of a game.
