Grundy · NewBrain AD

Grundy NewBrain — Controls

A Grundy NewBrain AD (1982), running in your browser. It was the machine that nearly became the BBC Micro, and it has a trick none of its rivals had: as well as driving a monitor it carries a sixteen-character vacuum fluorescent panel of its own, so it works with no screen attached at all. Both are on the page — the monitor on the left, the panel on the machine itself. Games load from cassette, and the page does the loading for you.

The two displays

The monitor is where programs draw: 40 or 80 columns of text, switched by whatever is running rather than by you. The glowing strip on the machine is the NewBrain's own VF panel, and it is not decoration — the firmware writes to it, so it lights up while the machine works even when the monitor has nothing to show.

Keyboard

Letters and digits map straight through, so you can simply type. The NewBrain's keys are mapped by physical position, not by what your own keyboard is set to, so the layout is the same whichever one you use.

Punctuation worth knowing

The NewBrain puts several characters somewhere a modern keyboard does not, and the keys are mapped by position, so a few come out differently from what is printed on your own keycaps. These are the ones that catch people out:

Two of the machine's keys are not reachable from a PC keyboard: REPEAT, which had no modern equivalent to borrow, and the £ / * key. Nothing bundled here asks for either.

Loading a game

Pick a game from the menu and it loads and starts itself. There is nothing to press.

Behind that the machine is doing exactly what it always did. A NewBrain has to be told to listen before a tape starts, so the page types LOAD "" for it, runs the tape in, waits for the machine to take the last block, and types RUN. You can watch the whole thing happen on screen.

It is not instant. These are real cassette signals being decoded a bit at a time, as the machine would have done it, and a long program genuinely takes a while — the largest game here is a little over seventeen thousand bytes, which on real tape was a minute of sitting and waiting. We run the machine flat out until the load is done, so it costs you seconds instead.

Sound

There isn't any, and that is the machine rather than the page. A NewBrain AD shipped with no sound hardware — sound was to be an add-on, like the discs — so these games are silent, as they were in 1982. Nothing needs unlocking and there is no volume to find.

Tips

  • Typing works as soon as the machine has booted, which takes a few seconds — power-up is on a real 5.6 second delay, so the first moments after the page opens are the machine genuinely warming up.
  • Esc gets you out of a stuck program and back to the READY prompt.
  • Click the page before typing if the keys seem to do nothing — the machine only sees the keyboard while the page has focus.
  • Open the page without choosing a game and you get the bare machine at its own BASIC prompt, ready to be typed into.
  • If a load ever goes astray, reload the page — the game is fetched and loaded again from the start.
