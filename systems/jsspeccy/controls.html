Sinclair Spectrum — Controls

A 48K Spectrum with its rubber-key keyboard. The bundled titles are .z80 snapshots — they boot mid-game, so most controls live in the game itself.

Spectrum keyboard

Most letter / number / symbol keys map directly. The Spectrum's shift behaviour is split into two keys:

KeySpectrum key
ShiftCAPS SHIFT
CtrlSYMBOL SHIFT
EnterENTER
BackspaceCAPS SHIFT + 0 (DELETE)

USB gamepad

Every bundled game supports a USB gamepad. The pad presses each game's own keys — D-pad or left stick to move, and face buttons for the game's action. The exact mapping is on each game's controls page; an idle pad sends nothing, so keyboard play is unaffected.

Cursor keys and joystick options

The arrow keys press the Spectrum cursor keys (CAPS SHIFT + 5/6/7/8), so games offering a cursor joystick option (Protek / AGF) work from the arrows. Games offering Sinclair Interface 2 use 6 7 8 9 + 0 for Player 1. No joystick hardware is emulated — in games that ask, pick the keyboard (or cursor) option.

Common in-game key schemes

Spectrum games rarely share a key layout — each title's own scheme is on its controls page. The recurring ones:

SchemeUsed by
Q W E R TUltimate's house layout — left / right / down / up / fire (Atic Atac, Pssst, Underwurlde; Sabre Wulf swaps E/R)
Alternating columns: QET… left, WRY… rightMatthew Smith's Miner Willy games (Manic Miner, Jet Set Willy) — any left-column key goes left, any right-column key goes right; Space jumps
Q A O PUp / down / left / right — the most common redefine and Skool Daze's default
Z XLeft / right in many later games (Dizzy and others)

UI

This emulator shows a central play overlay on first load — click it to start emulation (browsers require a user gesture before Web Audio can start). After that, the canvas drives input directly.

Mapping follows JSSpeccy 3.2 (GPL-3.0, gasman/jsspeccy3). The full key reference lives in the upstream README.
