Nintendo Game Boy — Controls

The Game Boy line, running in your browser. The bundle boots in Game Boy Color mode, so it plays both the original 1989 monochrome carts (auto-colourised) and full Game Boy Color titles. Click the game area to enable sound and controls.

Controls

The universal Game Boy keyboard layout — D-pad on the arrows, the two face buttons on Z / X:

KeyGame Boy
↑ ↓ ← →D-pad
XA button
ZB button
EnterSTART
ShiftSELECT

The save / load controls in the bottom-left corner each open a menu of five save slots — a full machine snapshot per slot, so they work mid-game even in titles with no save of their own. Slots are per-game and survive a reload. To restart, reload the page.

Cartridge saves (battery RAM, e.g. Pokémon, Zelda) persist in the browser between sessions; the Save/Load menus are a separate snapshot system with five slots.

Emulator: gambatte (GPL-2.0, libretro core) under EmulatorJS (GPL-3.0). Both shipped locally from this site; no network calls at runtime.
