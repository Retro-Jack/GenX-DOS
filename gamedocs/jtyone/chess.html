Chess (Psion)

Psion, 1981 — David Potter's chess engine, fitted into 1K of ZX81 RAM. Psion's very first commercial release; later 16K versions added levels and book openings.

A full chess engine running in a kilobyte. The interface is text-coordinate (you type "E2 E4" to move pawn from e2 to e4); the board is rendered as a small grid using ZX81 block graphics. Eight strength levels in the 16K edition; the 1K original played only one mode.

Getting started

  1. Press Enter at the title to start a new game.
  2. Choose strength level 1–8 (16K version) or just press Enter for the default.
  3. You play White by default. Enter moves in coordinate notation: source square then destination, e.g. E2 Space E4 Enter.
  4. The computer responds; the board redraws with the new position.

The screen goes black while the computer is thinking. Like a lot of ZX81 software that needs every scrap of CPU speed, the engine computes in the machine's FAST mode, which switches off the display while it runs — so the picture blanks to black during the computer's move and snaps back the moment it has chosen. It is not a crash or a frozen tab; just wait. The darker it stays, the harder it's thinking — 30+ seconds is normal at the higher strength levels.

Controls

A gamepad has no role here — moves are typed as coordinates, all keyboard by design.

Move notation

  • Pawn move: source square + destination, e.g. E2 E4
  • Capture: same syntax — the engine knows from the board state, e.g. D5 E4
  • Castling: move the king two squares — e.g. E1 G1 for kingside castle
  • Promotion: append the piece letter, e.g. E7 E8 Q for promote to queen

Strategy

  • This is a chess engine, not a teacher. No move suggestions, no undo on most versions, no hint feature.
  • Strength level 1 plays openings book moves and basic tactics; level 8 thinks for noticeable seconds per move on the original 3.5 MHz Z80.
  • Move clock is real on the higher levels. The engine searches in FAST mode with the display switched off, so the screen sits black while it works (see the note under "Getting started") — 30+ seconds at level 6+.
  • Save with S on the 16K edition writes the position to tape (the 1K edition has no save) — but tape saves aren't preserved once you close the tab, and this engine has no save-state button, so a saved position won't carry between sessions.
