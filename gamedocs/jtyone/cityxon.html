Home Computer · Sinclair ZX81

City of Xon

Macronics, 1982. Text-graphic adventure: explore an abandoned city, solve puzzles, and find your way out. One of the earlier ZX81 adventures to combine room graphics with verb-noun parser.

You wake in the deserted city of Xon with no memory. Every room shows a small graphic plus text description. Pick up objects, examine them, and use them to unlock doors, defeat creatures, and find the path to the city's gate.

Getting started

  1. Tape auto-loads. Press Enter at the title to start.
  2. You wake in a single starting room. Read the description and the screen graphic.
  3. Type two-word commands: LOOK, GO NORTH, GET KEY, USE KEY.
  4. Carry useful items; the city's puzzles are inventory-based.

Common commands

This emulator is keyboard-only — USB gamepads aren't supported.

CommandUse
GO <dir>Move (N/S/E/W/UP/DOWN)
LOOKRe-describe the room
EXAMINE <item>Inspect for clues
GET / DROP <item>Inventory
USE <item>Apply to current situation
OPEN <door>If you have the right key
HELPBrief verb list

Strategy

  • Read every screen graphic. Some clues are only visible in the picture, not the text.
  • Examine everything. Hidden compartments and clue-objects only describe themselves when EXAMINE'd, not on default room entry.
  • Limited carry. The ZX81's 16K is tight — the parser caps inventory at a small number of items.
  • Map carefully. No automap; the city's layout is large and not strictly grid-shaped.
