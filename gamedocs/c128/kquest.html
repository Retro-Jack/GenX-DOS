Home Computer · Commodore 128 (VDC 80-col)

Knight's Quest

Homebrew, early 1990s — a text adventure / strategy hybrid written natively for the C128's 80-column VDC mode. The wider screen lets the parser show map snippets alongside its room descriptions, which the 40-col C64 versions couldn't.

Boots into VDC 80-column mode. Pure text-and-typed-command adventure: explore the kingdom, gather party members, equip weapons and armour, and storm the dark tower at the end. Read every room description carefully — the 80-col layout means the verb-noun parser sometimes hides hints in the right-hand column.

Getting started

  1. The .d64 autoboots into VDC 80-col; click the canvas first.
  2. Press Enter at the title; type your character's name.

Controls

Standard verb-noun text-adventure parser. Useful commands:

Typed commandEffect
LOOKRe-describe the current room
N S E W U DMove (single-letter shortcuts)
GET <item> / DROP <item>Inventory management
INV or IList what you're carrying
USE <item>Activate an item (potion, key, scroll)
ATTACK <creature>Initiate combat
SAVE / LOADDisk save/load (uses EmulatorJS state in the browser)

Strategy

  • Map as you go. 80-col text adventures still use grid rooms; pen-and-paper or a side text file pays off fast.
  • Read item descriptions. Each pick-up often has a one-line property the parser only mentions on the EXAMINE verb — vital for puzzle-key items.
  • Save before combat. Combat is dice-rolled and unforgiving; EmulatorJS save-state before any first encounter with a new creature type.
  • Visit shops first. Early gold buys better starting gear; the tower run is impossible without leather + a real sword.
