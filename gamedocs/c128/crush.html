128 Crush

Homebrew, mid-1980s — a Commodore 128-distinctive demo running natively in C128 mode on the VICII 40-column screen, leaning on BASIC 7.0 features and the C128's 128 KB RAM that the C64 couldn't match. Bundled here because it actually exercises C128-only hardware rather than running as a C64 mode passenger.

Runs as a stand-alone .prg on a cold C128. The whole point of including this in the menu is to demonstrate that we boot into C128 native mode (not C64 mode via Commodore+Run/Stop) — this emulator has vice_c128_go64='disabled' set so the BASIC 7.0 prompt is the landing pad.

Getting started

  1. The .prg auto-loads via this emulator's autostart; click the canvas first.
  2. Press Enter or L Ctrl (fire) at the title prompt.

Notes

  • It's a 40-column program. The play.html wrapper reads each game's video field from games.json; this one stays on VICII (40 columns) not VDC (80 columns).
  • Cold-restart with the canvas focused. If a tape-load sound loops, use the emulator's Restart button to cold-boot back to READY..
  • BASIC 7.0 is yours after. Once the demo ends, Scroll Lock drops you back to BASIC where you can LIST the program if it left itself in memory.
