Home Computer · Commodore PET

Adventureland

Scott Adams, 1979 — the first commercial home-computer text adventure. Originally written on a TRS-80, ported almost immediately to every machine that could run BASIC, including this PET build.

You wake in a forest. There are 13 treasures hidden across the world; bring each one back to the magic mirror at the start. Two-word commands (verb + noun). The whole game runs in 16 KB.

Getting started

  1. Game autoboots — VICE autostarts the .prg straight into the title.
  2. Click the canvas first so the emulator receives keyboard input.
  3. Type NORTH, LOOK, or any of the two-word commands below.

Command basics

VerbWhat it does
LOOKRe-print the room description and exits
N S E W U DMove (cardinal + up/down)
GET <noun>Pick up an object
DROP <noun>Drop an object
INVENTORY (or I)List what you're carrying
SCORETreasures returned so far
SAVE GAMESave state (works in-emulator via VICE state slots)

Strategy

  • Map as you go. 30+ rooms with non-Euclidean exits in places — paper maps were the period-correct tool.
  • Every object is in play. If something is mentioned in the room text, you can probably interact with it.
  • The bees. The bear in the forest blocks a critical path; the bees are the answer, but only with the right vessel.
  • Treasures don't all want to be carried. Some need a specific environment to "unlock" their treasure status.
