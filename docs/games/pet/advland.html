Adventureland

1979 — Scott Adams' text adventure, modified for the PET by Jeff Jessee in May 1979. Find the thirteen treasures hidden around Adventureland and bring them back to where they belong.

System help — the Commodore PET controls

You start in a forest, where a voice booms out that treasures have an * in their name and that HELP gives a hint. Each place is described with the things you can see and the exits you can take, and you move and act by typing short commands of a verb and a noun. Treasures look like *MAGIC MIRROR*. Somewhere there is a sign reading LEAVE TREASURE HERE — SAY SCORE: that's where treasures are stored, and SCORE tells you how many you've brought back.

Getting started

  1. Click the game area to enable controls.
  2. Read the welcome and press any key at hit RETURN to begin ADVENTURE.
  3. USE SAVED GAME (Y or N) — just press Return; the answer N is already filled in.
  4. At tell me what to do, type a command and press Return.

Commands

This emulator is keyboard-only — USB gamepads aren't supported.

TypeWhat it does
N S E W U DGo north, south, east, west, up or down — short for GO NORTH and so on
GO placeGo somewhere, e.g. GO TREE (T is short for it)
TAKE / DROP thingPick something up or put it down
INVENTORYList what you're carrying
LOOKDescribe where you are again
SCOREHow many treasures you've stored, and a rating out of 100 — works from anywhere
HELPAsk for a hint

The game's own hint lists more verbs to try: LOOK, JUMP, SWIM, CLIMB, THROW, FIND, GO, TAKE, INVENTORY, SCORE. If it doesn't know a word it says you use word(s) I don't know!

SAVE GAME saves to cassette, which this emulator doesn't have — at OUTPUT TAPE READY TO SAVE GAME type N and press Return, as there's no tape to save to. A game can't be carried over between visits.

Tips

  • Map as you go. As the welcome warns, going back the opposite way won't always take you back to where you were.
  • Watch your light. Once you have a light it doesn't last for ever — the game counts down the turns it has left.
  • Read everything. Signs and messages around Adventureland carry clues, and some things only become useful with the right item in hand.
