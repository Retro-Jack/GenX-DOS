Personal Computer · Commodore PET

Commodore PET BASIC 2

1977 — the first machine Commodore built, and the oldest BASIC prompt on this site.

System help — the Commodore PET controls

The PET arrived as one piece — keyboard, tape deck and monitor in a single steel case — and this is what it put on its green screen. Everything after it on the Commodore shelf grew from this BASIC. There is no colour and no sound to speak of; what there is, is a prompt, a cursor, and the PETSCII character set that gave Commodore machines their look for the next decade.

Getting started

  1. The screen shows the startup message and a cursor. Type at it.
  2. PRINT 2+2, then Enter.
  3. Programs take line numbers: 10 PRINT "HELLO", 20 GOTO 10, RUN.
  4. Esc is RUN/STOP on this machine and stops a running program.

Keys that are not where you expect them

This machine reaches its stop key more directly than the others on the Commodore shelf.

KeyboardAction
EscRUN/STOP — stops a running program. The PET answers with BREAK and READY.
EnterRETURN
BackspaceINST/DEL

What you can type

GOTO GOSUB RETURNJump about

CONTCarry on after a stop

One trap worth knowing: if a BASIC program asks you a question, type an answer before pressing Enter. A bare Enter at an INPUT prompt stops the program rather than answering it — that is the PET being itself, not a fault here.

Tips

  • It is a calculator too. PRINT 2+2 and press Enter. No program required.
  • Line numbers decide the order, not the order you typed them. Number in tens so there is room to squeeze lines in later.
  • Editing is done on screen. Move the cursor up to a listed line, change it, press Enter on it. That re-enters the whole line.
  • Nothing is kept. SAVE works, and the result goes when the tab closes.
