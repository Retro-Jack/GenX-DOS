Home Computer · ZX Spectrum

Knight Lore

Ultimate Play The Game, 1984 — Tim & Chris Stamper. The first 3D isometric "Filmation" engine; a generational leap that redefined what an 8-bit home computer could render.

System help — the Sinclair Spectrum controls

Sabreman has been cursed: by day he is a man, by night a werewolf. Find the Wizard's castle, collect 14 ingredients (one per room), and brew the cure before time runs out. Each room is a tiny isometric tableau full of bouncing platforms, conveyor blocks, deadly statues, and item containers.

Getting started

  1. Press Space at the title to start.
  2. Sabreman enters the castle — explore in 8 directions. Pick up an item by walking over it; drop it into the wizard's cauldron room.
  3. Each in-game day costs a life off the timer at the top. Plan an efficient route — the castle map doesn't shuffle, but every dead end costs time.

Controls (default)

This game supports a USB gamepad — left/right on the D-pad or stick turns, up walks forward, A jumps and B picks up / drops.

KeyAction
Bottom row (Z X C … Space)Turn left / right (alternate keys)
3rd row (A–L)Walk forward
2nd row (Q–P)Jump
Top row (1–0)Pick up / drop

Strategy

  • Jump timing is everything. Hold longer for higher arcs over wider gaps; the rhythm is fixed not analogue.
  • Werewolf timer. At sunset Sabreman transforms; werewolf form can't carry items. Plan ingredient pickups for daylight hours.
  • Map the castle. Forty rooms, fixed layout. Penned routes save days; wandering kills your life timer.
  • Ingredients are class-specific. Some items only matter in werewolf form, others only when human. Drop what you can't use.
