Sinclair BASIC

1982 — the 48K Spectrum, where you do not type the keywords: you press them.

System help — the ZX Spectrum controls

The Spectrum's party trick is that PRINT is one keypress. Sinclair BASIC puts a keyword on every key and the machine decides, from what it is expecting, whether your keypress means a letter or a whole word. Press P when it wants a command and PRINT appears complete. It saved memory and it saved typing, and it means that anyone arriving from a normal keyboard spends their first five minutes baffled.

Getting started

  1. The cursor shows a letter telling you what mode it is in. A K means the next key is a keyword.
  2. Press P. The whole word PRINT appears.
  3. Now type 2+2 and press Enter.
  4. For a program: 1 0 then P, then the text, then Enter.

Keys that are not where you expect them

The cursor letter is the whole system. It tells you what the next keypress will produce.

KeyboardAction
K cursorKeyword mode — one key gives a whole keyword. This is what you get at the start of a line
L cursorLetter mode — keys type themselves, which is what you want after the keyword
C cursorCapitals
E cursorExtended mode, for the keywords printed above and below the keys
G cursorGraphics characters

What you can type

TypeWhat it does
PRINT (P)Print, or calculate
LIST (K)Show the program
RUN (R)Start it
NEW (A)Throw it away
LET (L)Assign a variable — Sinclair BASIC insists on it
GO TO (G)Jump. Note the space: it is two words here
FOR / NEXTLoop
INK PAPER BORDERColour
PLOT DRAW CIRCLEGraphics, 256×192
BEEPThe one-bit speaker

LET is not optional on a Spectrum. A=1 will not do; it has to be LET A=1, and the LET is a single keypress anyway.

Tips

  • Watch the cursor letter, not the keyboard. It tells you whether the next key is a word or a letter.
  • GO TO is two words on a Spectrum, and one keypress.
  • Colour is per character square, which is why Spectrum graphics have that famous clash.
  • Nothing is kept once the tab closes.
