Personal Computer · Atari 800XL

Atari BASIC

1983 — the handsome later model, with a keyboard you could actually type on. The BASIC is Atari's own, and it has opinions.

System help — the Atari 800XL controls

Atari BASIC is unlike the others on this site in one immediately obvious way: it will not let you enter a line with a mistake in it. Press Enter and it checks the line there and then, and if it does not like it the offending part comes back at you in inverse video. People either loved that or found it insufferable. It also has real commands for graphics and sound, which the Commodore 64 sitting a few rows up does not.

Getting started

  1. You get READY and a cursor.
  2. PRINT 2+2, then Enter.
  3. 10 PRINT "HELLO", 20 GOTO 10, RUN.
  4. F8 is BREAK and stops it.

Keys that are not where you expect them

The console keys down the side of the real machine, and the BREAK key, are on the function row here.

Without BASIC switched in, one of these machines with nothing in the cartridge slot comes up in the Memo Pad — a screen you can type on that does nothing whatsoever with what you type. Every other entry on this shelf boots with BASIC out of the way, because a game wants the memory.

Tips

  • It checks each line as you type it. Press Enter on a line with a mistake and it comes straight back with the bad part in inverse video. No other BASIC here does that.
  • GRAPHICS 8 then PLOT and DRAWTO is the quickest way to get something on screen worth looking at.
  • Line numbers decide the order. Number in tens and leave yourself room.
  • Nothing is kept. Close the tab and the program is gone.
