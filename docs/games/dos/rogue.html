Rogue

1986 — originated by Michael C. Toy and Kenneth C.R.C. Arnold, adapted for the IBM PC by Jon Lane, with design contributions from Glenn Wichman. Go down, find the Amulet of Yendor, come back up. Almost nobody does.

System help — the IBM PC controls

The game that named a genre. A dungeon drawn in characters, generated afresh every time you play, where death is permanent and the map you learned last time is no help at all. Everything in your pack is unidentified — a potion is a colour, a scroll is a nonsense word — and finding out what they are is done the hard way. This is the PC version, which asks your name before it will let you in.

Getting started

  1. It asks for a name. Type one and press Enter.
  2. You are on level one. The staircase down is >.
  3. Everything you pick up is a mystery until you use it, and some of the mysteries are unpleasant.
  4. When you die, that is the end of that character. There is no reloading.

Moving

Either the arrow keys or the letters under your right hand — the same eight directions, and the letters do the diagonals the arrows cannot.

KeyboardAction
h j k lLeft, down, up, right
y u b nThe four diagonals
>Down a staircase
<Up a staircase
.Rest for a turn
sSearch the walls beside you for a hidden door

A number typed before a command repeats it: 10s searches ten times. Saving works, but nothing here survives closing the tab.

Tips

  • Eat before you are starving. Hunger kills more early characters than monsters do.
  • Name things as you learn them. The c command exists because the game expects you to be keeping notes.
  • Search for doors. A room with no visible exit usually has one; s a few times against each wall.
  • Going down fast is how you die. The monsters scale with the depth and your equipment does not.
