Round 42

1986 — Elven Software Company. Forty-two rounds of invading ships, each round a new enemy with its own fighting logic to work out.

System help — the IBM PC controls

A descendant of the fixed shooters, but with more on its mind than most: forty-two rounds, each introducing a different enemy that behaves differently, and every fourth round a warp section you fly through rather than fight. Your ship carries phasor charges, which are scarce and which you will waste if you use them as a second fire button. Shareware, and generous with it — the whole game is here.

Getting started

  1. The shareware notice comes first. Press a key.
  2. From the menu: Enter begins, I gives the game's own instructions.
  3. A lightning bolt beside your score is a phasor charge. You start each ship with one.

Controls

From the game's instructions screen. Movement is on the numeric keypad, and holding a key keeps you moving.

KeyboardAction
Keypad arrowsMove — press to start moving, release to stop
Two keypad keys togetherDiagonal movement
F1Fire bullets
F2Fire the phasor
SpacePause
BackspaceSelf-destruct, if the situation is hopeless
F9 / F10Sound off and on
EscAbort the game

Tips

  • A charge every 7,500 points, and one at the start of each round. An extra ship comes at 7,500 too.
  • Each round is a puzzle about behaviour. The game says so itself: discover their fighting logic. What worked on round three is wrong on round four.
  • Save the phasor. It is the answer to a round you cannot otherwise survive, and you only have it if you did not spend it on one you could.
  • Warp rounds are flying, not shooting. Every fourth round, move left and right and thread the path.
  • Horizontal movement still works while you are regenerating after a hit — the game mentions it because it will save you.
