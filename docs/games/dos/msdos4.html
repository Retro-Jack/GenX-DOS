MS-DOS 4.00

1988 — Microsoft and IBM. Not a game: the operating system itself, and the only entry here you are expected to talk back to.

System help — the IBM PC controls

Every other entry in this bundle is a program that DOS would have loaded for you. This one is DOS. It boots from a 720K floppy into a command prompt and waits, exactly as a PC did in 1988, and everything you do happens inside the tab — nothing is written to your machine and nothing survives a reload.

Getting started

  1. It boots, names itself, and asks for the date and then the time. Press Enter twice to accept what it has — the machine thinks it is January 1980 and nothing here minds.
  2. You land at A>. That is the prompt; type at it.
  3. DIR then Enter lists what is on the disk.
  4. Typing the name of a program runs it. MEM and CHKDSK are good first pokes.
  5. Nothing you type can hurt anything. Reload the page and the disk is back as it was.

Some programs on the disk expect hardware this emulator has no reason to provide — a printer for PRINT, a second drive for DISKCOPY, a hard disk for FDISK. They are on the disk because they shipped with DOS, not because they will do much here.

Tips

  • Pipes and redirection work. DIR | SORT, DIR > LIST.TXT, TYPE LIST.TXT | MORE — all of it behaves as you would hope.
  • F3 repeats the last line. That was the whole command history, and it is why DOS users typed so carefully.
  • Write a batch file. COPY CON GO.BAT, type your lines, then Ctrl+Z and Enter. Now type GO.
  • Filenames get eight characters and three. There is no way round it and nothing here will pretend otherwise.

What you are actually running

Microsoft published the MS-DOS 4.00 source code under the MIT licence in 2024. This disk is that source, compiled with the period tools that came with it, so IO.SYS, MSDOS.SYS, COMMAND.COM, the boot sector and every program listed above were built here rather than copied from a 1988 disk. The three-line CONFIG.SYS is ours. There is deliberately no AUTOEXEC.BAT: without one, DOS asks for the date and the time and leaves you at a bare A>, which is what a boot floppy did in 1988 and what it should look like here.
