Handheld · Sega Game Gear (1991)

Shinobi

Sega's ninja on the go — a colourful 8-bit action-platformer where you rescue captured ninja and gain their powers, leading into a showdown with the Neo Zeed.

System help — the Sega Game Gear controls

Fight through five missions as the ninja Joe Musashi. Start with only your fists; rescue a hostage ninja in each stage and you unlock that character's special weapon (shuriken, kunai, sword, etc.) for the next mission. Slash and throw your way past the Neo Zeed's goons to each boss.

Getting started

  1. Click the game area to enable sound and controls, press Enter (Start); pick a stage from the select screen.
  2. Free the caged ninja in a stage to carry that ninja's weapon onward.

Strategy

  • Rescue every ninja. Each one's weapon is a real upgrade — going in bare-fisted against a boss is rough.
  • Jump-attacks control the spacing on most enemies; learn to strike at the top of the arc.
  • Memorise boss tells. Each Neo Zeed boss has a punishable pattern — patience beats rushing.
  • Use the save / load buttons before bosses; lives are limited. Five save slots per game — pick 1–5 from the save or load menu.
