Commodore 64 BASIC

1982 — Microsoft BASIC, as Commodore shipped it. The screen almost every British bedroom saw first.

System help — the Commodore 64 controls

This is the machine with nothing loaded: the BASIC that came up when you switched a 64 on, waiting at READY. for you to type. It is BASIC V2, which was already old when the 64 was new — there is not one command here for the sprites or the sound chip the machine is famous for, and getting at either means POKEing numbers into addresses out of a magazine. That is not a fault of this page; it is what everybody actually did.

Getting started

  1. The cursor is flashing after READY.. Type at it.
  2. Try PRINT 2+2 and press Enter.
  3. Type a program with line numbers: 10 PRINT "HELLO", then 20 GOTO 10, then RUN.
  4. Stop it with Scroll Lock — that is RUN/STOP.

Tips

  • It is a calculator too. PRINT 2+2 and press Enter. No program required.
  • Line numbers decide the order, not the order you typed them. Number in tens so there is room to squeeze lines in later.
  • Editing is done on screen. Move the cursor up to a listed line, change it, press Enter on it. That re-enters the whole line.
  • Nothing is kept. SAVE works, and the result goes when the tab closes.
