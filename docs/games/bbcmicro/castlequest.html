Castle Quest

Micro Power, 1985 — Tony Sothcott. A flip-screen puzzle-platform-adventure through a wizard's castle, billed on its own title screen as "probably the most challenging game ever devised for the BBC micro" — and it means it.

Somewhere in the castle the wizard has hidden his treasure; you have to explore every room to find it. Progress is a puzzle of objects — a stool, a sword, a wand, a bucket, torches, a ruby, an aqualung — that you pick up, carry, drop and throw to cross hazards and open the way on. You can only hold one thing in hand, but a four-slot backpack lets you stash spares for later. Ladders, jumps, and things that want you dead do the rest.

Getting started

  1. Press Space at the title to begin.
  2. Explore room to room — the screen flips as you reach an edge. Pick things up and work out what each is for: the puzzle is half platforming, half inventory.
  3. You carry one object in hand; S stores a spare in the backpack and R retrieves it, with f0–f3 choosing the slot. Throw the held object with the arrow keys to reach switches, jam hazards, or deal with a nasty.

Controls

Castle Quest uses one fixed key layout. The BBC's * and ? keys aren't where a PC keyboard puts them — this emulator maps the BBC *: key to your PC apostrophe ' and the BBC / ? key to /, so press those for up/down. The BBC's red function keys f0–f3 map to F10 and F1–F3.

Castle Quest is a keyboard game. With pick-up, drop, store, retrieve and a four-way throw all live at once, it has more actions than a gamepad maps cleanly — so this one is played on the keys.

Strategy

  • Every object has a job. The sword, wand, bucket, stool and the rest each solve a specific obstacle — if a room looks impassable, you're probably missing (or holding the wrong) item.
  • The backpack is your lifeline. You can only hold one thing, so stash spares with S and pull the right one out with R before a tricky room rather than during it.
  • Throwing is a tool, not just a weapon. A well-aimed throw can trigger something across a gap you can't jump — line up with the arrow keys.
  • Snapshot before the hard bits. Castle Quest has no in-game save, so use the save / load buttons at the bottom-left of the browser window — five slots — to bank progress before a leap of faith. You'll want them; the title screen isn't bluffing.
