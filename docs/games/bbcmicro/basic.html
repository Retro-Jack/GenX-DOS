BBC BASIC

1981 — the machine the BBC put its name to and British schools filled up with. Widely held to be the best BASIC of the eight-bit era, and with reason.

System help — the BBC Micro controls

Sophie Wilson's BASIC is the one that makes the others look dated. It has named procedures and functions, REPEAT…UNTIL and WHILE…ENDWHILE loops, local variables, a real ELSE, and — the part nobody else attempted — a 6502 assembler built into the language, so you can drop into assembly in the middle of a BASIC program and call it as a procedure. If you learned to program on one of these, every BASIC you met afterwards was a step down.

Getting started

  1. You get a > prompt.
  2. PRINT 2+2, then Enter.
  3. MODE 1 changes the screen; MODE 7 is teletext.
  4. Type *CAT to catalogue the disc. Commands beginning with * go to the operating system rather than to BASIC.
  5. Esc stops a running program.

Keys that are not where you expect them

The star commands are the thing to know: an asterisk hands the rest of the line to the machine's operating system.

KeyboardAction
EscStop a running program
F10The machine's own f0 key — a PC keyboard has no F0
F1–F9The machine's f1 to f9

What you can type

TypeWhat it does
LISTShow the program
RUNStart it
NEWThrow it away
MODE nChange screen mode — MODE 7 is the teletext one
DEF PROC / ENDPROCNamed procedures, called by name
DEF FNNamed functions
REPEAT … UNTILA loop that tests at the bottom
WHILE … ENDWHILEAnd one that tests at the top
LOCALVariables that belong to one procedure
VDUSend control codes straight to the screen driver
[ … ]Inline 6502 assembly, in the middle of a BASIC program
*CATCatalogue the disc — an operating-system command, hence the star
CHAIN "name"Load and run a program from disc

A disc that starts at the > prompt instead of running something can usually be started with *EXEC !BOOT.

Tips

  • Procedures, not GOSUB. DEF PROCname and call it as PROCname. It is why BBC BASIC programs are readable.
  • MODE 7 costs almost no memory — it is the teletext chip doing the work, which is why so much BBC software used it.
  • The assembler is part of the language. Square brackets, 6502 mnemonics, and BASIC variables as labels.
