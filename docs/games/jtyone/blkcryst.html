Black Crystal

Carnell Software, 1982. Five-part graphic-text adventure with character-class selection; one of the earliest fantasy adventures with on-screen graphics on the ZX81.

You're a hero on a quest to find the Black Crystal of Beroth and save the realm. The adventure spans five chapters, each loaded from tape in sequence. The interface is text-input ("GO NORTH", "GET SWORD"), but every location has a small graphic showing where you are. Combat is dice-roll vs monster stats.

Getting started

  1. Tape loads Chapter 1 automatically.
  2. Choose your class: Fighter, Wizard, or Ranger. Each starts with different stats and inventory.
  3. Type commands at the prompt — two-word verb-noun (e.g. "GO NORTH", "GET LAMP", "FIGHT ORC").
  4. Complete the chapter's objectives, then save the character state to load Chapter 2.

Common commands

A gamepad has no role here — Black Crystal is a typed-command adventure, all keyboard by design.

VerbUse
GO <direction>Move (N / S / E / W / UP / DOWN)
GET <object>Pick up
DROP <object>Discard
USE <object>Activate / consume
FIGHT <creature>Engage combat
CAST <spell>Wizard only — name the spell
LOOKRe-describe current location
INV / IInventory
SAVEWrite character state to tape (for next chapter)

Note: tape saves aren't preserved once you close the tab, and this engine has no save-state button — progress can't be carried between sessions, so play the chapter sequence in one sitting.

Strategy

  • Map every room. Pen-and-paper; the chapter structure means you can't backtrack across tape loads.
  • Fighter is easiest. Wizard's spells run out fast; Ranger's tracking edge needs careful inventory management.
  • SAVE before risky combat. Death sends you back to the chapter restart.
  • Two-word parser. Multi-word objects are abbreviated (e.g. SWORD not "RUSTY BROKEN SWORD") — try the shortest noun first.
