Personal Computer · Sinclair ZX81

ZX81 BASIC

1981 — black and white, 16K, and the machine that put a computer in a British house for under a hundred pounds.

System help — the Sinclair ZX81 controls

The ZX81 is the Spectrum's older, sparser parent: no colour, no sound, and a membrane keyboard that does not so much click as relent. It uses the same single-keypress keywords, driven by a cursor letter that tells you what the next key will do. Everything about it was built down to a price, and it worked — this is the machine a great many people in Britain met first.

Getting started

  1. The cursor shows a letter. K means the next key is a keyword.
  2. Press P. PRINT appears whole.
  3. Type 2+2 and press Enter.
  4. Space is BREAK and stops a running program.

Keys that are not where you expect them

The cursor letter tells you what the next keypress produces — the same system the Spectrum inherited.

KeyboardAction
K cursorKeyword — the first letter of a keyword types the whole word (P gives PRINT, L gives LET)
L cursorLetters type as themselves, which is what you want after the keyword
F cursorFunction mode — reached with Shift+Enter, for things like SIN and RND
G cursorGraphics blocks — Shift+9 in and out

PLOT UNPLOTThe chunky 64×44 graphics
SLOW / FASTWhether the machine keeps drawing the screen while it thinks

SLOW and FAST have no equivalent anywhere else here. The ZX81's processor generates the picture itself, so in FAST mode the screen goes blank while the program runs and comes back when it stops.

Tips

  • Watch the cursor letter. Nothing about the keyboard makes sense without it.
  • Every key is live BASIC. There is no such thing as an inert keypress at this prompt.
  • FAST blanks the screen and roughly quadruples the speed. It is not a fault.
  • Nothing is kept once the tab closes.
