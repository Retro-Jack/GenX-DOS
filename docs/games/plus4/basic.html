Personal Computer · Commodore Plus/4

Commodore Plus/4 BASIC 3.5

1984 — “the productivity computer with software built in” — a four-program office suite in ROM that the magazines were merciless about. Its BASIC, though, is far better than the 64's.

System help — the Commodore Plus/4 controls

This is the BASIC Commodore should arguably have put in the 64. Where the 64 makes you POKE numbers into addresses to draw a line or make a noise, BASIC 3.5 has actual commands for both — CIRCLE, PAINT, SOUND — along with loops that do not need line numbers, a renumber command, a tracer for when a program misbehaves, and disk commands you can read out loud. The machines sold badly. The BASIC deserved better.

Getting started

  1. The cursor is waiting after the startup message.
  2. PRINT 2+2, then Enter.
  3. Try the graphics: GRAPHIC 1, then CIRCLE 1,160,100,60.
  4. GRAPHIC 0 puts the text screen back. Scroll Lock is RUN/STOP.

There is a HELP command, which is more than most machines of the period offered: run a program that fails and HELP lists the line it failed on with the offending part in flashing characters.

Tips

  • It is a calculator too. PRINT 2+2 and press Enter. No program required.
  • Line numbers decide the order, not the order you typed them. Number in tens so there is room to squeeze lines in later.
  • Editing is done on screen. Move the cursor up to a listed line, change it, press Enter on it. That re-enters the whole line.
  • Nothing is kept. SAVE works, and the result goes when the tab closes.
