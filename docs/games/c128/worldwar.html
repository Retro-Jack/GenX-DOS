World at War

Homebrew, 2017 — a modern BASIC 7.0 strategy game written specifically for C128 native mode. Showcases the language extensions Commodore added in BASIC 7.0 (sprite control, sound, graphics primitives) that BASIC 2.0 on the C64 lacks.

Boots into the BASIC 7.0 prompt and immediately RUNs its main file. Turn-based wargame on a tile map — manoeuvre units, attack adjacent enemies, manage resources. The 40-column VICII screen and BASIC's SPRDEF + SCNCLR commands keep the UI tight. Code is human-readable in BASIC if you stop the run and LIST — a good window into BASIC 7.0 for anyone who learned BASIC 2.0 first.

Getting started

  1. The .prg auto-loads + runs; click the game area to enable sound and controls.
  2. At the title menu, pick a side and difficulty with the number keys.

Strategy

  • End-turn discipline. Each side moves all its units in a turn; don't leave a unit exposed without supporting fire from an adjacent friend.
  • Read the code if stuck. Stop the program with Scroll Lock then LIST — the BASIC source explains the combat resolution rules that the in-game UI summarises.
  • Save state often. No in-game save in homebrew; lean on the save / load buttons between turns on tough levels. Five save slots per game — pick 1–5 from the save or load menu.
