Console · GCE Vectrex

Cosmic Chasm

GCE, 1982 — port of Cinematronics' 1981 vector arcade. The only Vectrex game directly adapted from another vector arcade.

You fly a ship through a network of rooms inside the Cosmic Chasm, blowing up alien generators and dodging or shooting hostile aliens. Each room has multiple exits; clear a generator and exit to the next room. Limited shields per ship; collect power-ups; finish the chasm before the timer runs out.

Getting started

  1. Wait for the Vectrex BIOS intro.
  2. Press F (Button 4) to begin.
  3. Fly the ship with arrows; A fires forward.

Controls

This emulator is keyboard-only — USB gamepads aren't supported.

Strategy

  • Generator first. Each room has a central generator. Destroy it before exploring exits — clearing it unlocks the room's score bonus.
  • Don't linger. Aliens respawn if you stay too long.
  • Path-finding. The chasm is a fixed map. Memorise the shortest route to the deepest rooms for high-score runs.
  • Shield management. Your ship absorbs a few hits before exploding. Power-ups appear randomly; grab them in passing.

Vectrex controls

Stick rotates; F fires, D thrusts, A drills, S shields. The Vectrex's pseudo-analogue stick allows finer rotation than the typical 8-way grid.
