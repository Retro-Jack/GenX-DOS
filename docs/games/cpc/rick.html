Rick Dangerous

Firebird, 1989 — Core Design. The shamelessly Indiana-Jones-flavoured trap-platformer. Four levels, hundreds of fatal patterns you only learn by dying to them.

Rick crash-lands among the Goolu tribe and works through an Amazon temple, an Egyptian pyramid, a Schwarzendumpf castle, and a missile base. Walking-into-something is usually fatal — falling rocks, spike pits, dart traps, swinging blades. Memorise, retry, advance.

Getting started

  1. Click the game area to enable sound and controls.
  2. Press a key past the title to begin Level 1.

Controls

This game is keyboard-driven — its controls live on the CPC's own keys, so a gamepad doesn't apply here.

KeyAction
← →Walk / run
↑Jump (push up-left / up-right to jump that way; climb on ladders)
↓Duck / climb down
SpaceStab knife (hold ←/→ to stab that way)
Space + ↑Shoot pistol (6 bullets)
Space + ↓Lay dynamite (5 carried)

Strategy

  • Trap-by-trap memorisation. The game is honest about it — there's no "blind read"; you die, you remember, you retry.
  • Dynamite for blocked routes. Some rooms cannot be cleared without blowing a wall — save it for the obvious dead-ends.
  • Six bullets in the pistol. Reserve for guards you can't sneak; never waste one on a target you could jump past.
  • Pixel-perfect jumps. Rick's jump arc is fixed-length — line up with the platform edge before committing.
