Locomotive BASIC 1.1

1985 — the CPC 6128's BASIC, and one of the tidiest of the era.

System help — the Amstrad CPC controls

Locomotive BASIC came from a British firm that wrote it in a hurry and got it right anyway. It has proper interrupt-driven timers (EVERY and AFTER run a subroutine on a clock, which almost nothing else of the period offered from BASIC), windows you can define and print into, and sensible graphics and sound commands. The disc side is bolted on through AMSDOS, whose commands are prefixed with a bar.

Getting started

  1. The machine comes up with Ready and a cursor.
  2. PRINT 2+2, then Enter.
  3. CAT catalogues the disc; |DIR lists it alphabetically.
  4. RUN"name" loads and runs a program from disc.
  5. Esc twice stops a running program.

Keys that are not where you expect them

The bar commands are the ones to know. The bar is typed as Shift+\ on the real machine; here it is wherever your keyboard puts it.

KeyboardAction
EscPress twice to stop a running program
Page Up / Page DownThe fire button, when something wants one

The difference between CAT and |DIR is real and catches people out: the first is BASIC's own and shows sizes in the order it finds them, the second is AMSDOS's and sorts alphabetically without them.

Tips

  • EVERY 50,1 GOSUB 1000 runs a subroutine once a second while the rest of the program carries on. Very little else from this era could.
  • MODE 2 gives you 80 columns in two colours — the reason CPCs got used for work as well as games.
  • Bar commands come from the disc ROM, not from BASIC, which is why they look different.
