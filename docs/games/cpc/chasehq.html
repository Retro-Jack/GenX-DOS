Chase H.Q.

Ocean, 1989 — conversion of the 1988 Taito arcade. Drive a black Porsche, chase a wanted criminal's car, ram them into surrender before the time runs out.

Five missions. Each opens with Nancy on the radio describing the suspect — then a timer starts and you race forward chasing the marked car. Catch up, ram repeatedly, run the damage meter out, mission cleared. Five missions, five suspects.

Getting started

  1. Click the game area to enable sound and controls.
  2. Press a key past the briefing to start the chase timer.

Controls

This game is keyboard-driven — its controls live on the CPC's own keys, so a gamepad doesn't apply here.

KeyAction
← →Steer left / right
↑Accelerate
↓Brake
SpaceTurbo (3 per mission)
ShiftGear up (some versions; tap once after revving)

Strategy

  • Turbo on long straights. The timer is generous if you close the gap fast; save turbos for visible suspect-cars, not catching up to traffic.
  • Ramming geometry. Hit the back-corner of the target car; centre hits bounce off. Crash the suspect into oncoming traffic for free damage.
  • Don't crash. A wreck costs ~3 seconds of recovery time which the timer rarely forgives at higher missions.
  • Five missions, ~20 minutes. The original had no save, so it was a single-sitting game — but you can use the load/save buttons at the bottom-left to save-state between missions. Five save slots per game — pick 1–5 from the save or load menu.
