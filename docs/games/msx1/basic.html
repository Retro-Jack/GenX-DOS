Personal Computer · MSX1

MSX BASIC

1983 — the standard that nearly happened: one BASIC across machines from a dozen manufacturers.

System help — the MSX1 controls

MSX was an attempt to do for home computers what VHS did for video recorders — one specification, many makers, software that ran on all of them. It largely failed in Britain and thoroughly succeeded in Japan. The BASIC is Microsoft's, and a good one: proper graphics and sound commands, sprites you can address from BASIC, and a row of function-key labels along the bottom of the screen that tells you what the keys do.

Getting started

  1. The machine comes up at a BASIC prompt with the function-key labels along the bottom.
  2. PRINT 2+2, then Enter.
  3. SCREEN 2 gives you graphics; SCREEN 0 puts text back.
  4. Page Up twice, quickly, breaks out of a program that has hung.

Keys that are not where you expect them

The bottom line of the screen is a live key legend, which is the MSX's own idea and rather a good one.

KeyboardAction
Page UpSTOP. Press it twice quickly to break out of a hung program
F1–F5The function keys, labelled along the bottom of the screen
EnterRETURN

What you can type

TypeWhat it does
LISTShow the program
RUNStart it
NEWThrow it away
SCREEN nPick a display mode — 0 text, 2 graphics
COLORForeground, background and border
LINE CIRCLE PAINT PSETDrawing, as commands rather than POKEs
SPRITE$ PUT SPRITESprites, from BASIC
PLAYMusic, written as a string of notes
SOUNDStraight at the sound chip's registers
KEYRedefine what the function keys type
FOR … NEXT, IF … THEN, GOSUBThe usual

PLAY "CDEFGAB" is the quickest way to get a tune out of one of these. The string is a little language of its own — notes, octaves, tempo and length all go in it.

Tips

  • Watch the bottom line. It shows what the function keys are set to, and KEY changes them.
  • SCREEN 2 then CIRCLE (128,96),50 proves the graphics in two lines.
  • Sprites are a BASIC feature here, which on most machines of the period they were not.
  • Nothing is kept once the tab closes.
