Applesoft BASIC

1977 — Microsoft BASIC in the Apple ][+'s ROM, and the prompt a generation of American schools learned on.

System help — the Apple ][ controls

This is the Apple ][+ with no disk in the drive. Applesoft is Microsoft's BASIC with Apple's graphics bolted on, and unlike the Commodore machines it does have commands for the screen: HGR for high-resolution graphics, HPLOT to draw on it, GR for the chunky colour mode. What it does not have is any way to talk to a disk without the controller card, which is why so much Apple software begins by booting a disk rather than being typed.

Getting started

  1. With no disk inserted the ROM looks for one for about three seconds, then gives up and drops to the ] prompt.
  2. Type PRINT 2+2 and press Enter.
  3. Try 10 PRINT "HELLO": GOTO 10, then RUN.
  4. Ctrl+C stops it.

Keys that are not where you expect them

The prompt is ] rather than the > most machines use, which is how you know an Apple at a glance.

KeyboardAction
Ctrl+CBreak out of a running program
Ctrl+GBeep

What you can type

TypeWhat it does
LISTShow the program
RUNStart it
NEWThrow it away
PRINTPrint, or calculate
HOMEClear the screen
GR COLOR= PLOTLow-resolution colour blocks
HGR HCOLOR= HPLOTHigh-resolution graphics, 280×192
TEXTBack to the text screen
FOR … NEXT, IF … THEN, GOSUBThe usual machinery
PEEK POKE CALLMemory, and machine code
HTAB VTABPlace the cursor before printing

The three-second pause at start-up is the disk controller hunting for a disk that is not there. It is the machine behaving correctly, not the page being slow.

Tips

  • HGR then HPLOT 0,0 TO 279,159 draws a line and proves the graphics work.
  • HOME clears the screen, not CLS. Applesoft is full of small differences like that.
  • Applesoft is slow at graphics and everyone knew it; the fast stuff was machine code called from BASIC.
