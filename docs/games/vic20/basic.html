Commodore VIC-20 BASIC

1980 — the same BASIC as the 64, on the machine that got there first and had a good deal less room to do it in.

System help — the Commodore VIC-20 controls

The VIC-20 was the first computer of any kind to sell a million, and this is what it showed you when you turned it on. The BASIC is the same V2 the 64 later used, but the memory underneath it is not: an unexpanded VIC has 5K of RAM and gives you about three and a half of it for your program, which is why so much VIC software came on cartridge and why its type-in listings are so tightly written.

Getting started

  1. The cursor sits under the startup message. Type at it.
  2. PRINT 2+2, then Enter.
  3. A program needs line numbers: 10 PRINT "HI", 20 GOTO 10, RUN.
  4. Scroll Lock is RUN/STOP and stops it.

Tips

  • It is a calculator too. PRINT 2+2 and press Enter. No program required.
  • Line numbers decide the order, not the order you typed them. Number in tens so there is room to squeeze lines in later.
  • Editing is done on screen. Move the cursor up to a listed line, change it, press Enter on it. That re-enters the whole line.
  • Nothing is kept. SAVE works, and the result goes when the tab closes.
