Arcade · 1979 Nintendo

Space Fever

Nintendo, 1979 — Nintendo's answer to Space Invaders, with three game modes.

System help — the arcade controls

A fixed shooter with descending aliens, offering three variants selectable at the cabinet. Nintendo's arcade output before Donkey Kong is mostly forgotten, and this is the most competent of it.

Getting started

  1. Insert a coin — the coin slot at the top left, or 5.
  2. Press 1 player start — the 1P button, or 1.

Controls

One button, and a two-way stick rather than a four-way one.

GamepadKeyboardAction
D-pad, or the left stick← →Move
AZFire

The cabinet had three further buttons — Game A, Game B and Game C — that chose between the three variants, and the emulator’s driver defines all three. This browser build does not pass them through, though: pressing them changes nothing and the mode indicator at the bottom of the screen stays on (A). Tested rather than assumed. So it is Game A here, and only Game A.

Strategy

  • You get Game A. The machine had three variants on dedicated cabinet buttons, but only the first is reachable here, so there is nothing to choose between.
  • Cover degrades. The shields erode from your own fire as well as theirs; shooting through your own bunker is how it disappears.
  • They accelerate as they thin out. Fewer aliens means a faster formation, so the last few are the hardest.

No point values are documented for this cabinet.

Arcade controls

Coin on 5, start on 1, and the six cabinet buttons on Z X C V A S. The arcade controls page covers the panel in full.
