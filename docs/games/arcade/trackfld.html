Track & Field

Konami, 1983 — Track & Field, and a generation of bruised palms.

System help — the arcade controls

Six athletic events driven by hammering the run buttons for speed and timing a third for angle. Each event has a qualifying distance; miss it and the game ends there.

Getting started

  1. Insert a coin — the coin slot at the top left, or 5.
  2. Press 1 player start — the 1P button, or 1.

Each hundredth of a second slower costs 20 points. The available guide gives this table for the dash; the other five events are described individually rather than tabulated.

Strategy

  • Rhythm beats force. The run buttons reward a steady alternating rate you can hold, not the fastest burst you can manage for two seconds.
  • The angle button is a separate skill. In the jumps and throws the run only sets the speed; the release angle decides the distance, and 45 degrees is not always the answer.
  • Every event has a qualifying mark. Miss it and the game ends there and then, so an event you cannot clear is where your run stops.
  • Twenty points a hundredth. The scoring is fine-grained enough that small improvements in the dash are worth real points.

Arcade controls

Coin on 5, start on 1, and the six cabinet buttons on Z X C V A S. The arcade controls page covers the panel in full.
