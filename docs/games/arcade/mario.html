Mario Bros.

Nintendo, 1983 — Mario Bros., where the plumbing and the brother both arrive.

System help — the arcade controls

Two plumbers clear pests from a sewer by hitting the platform underneath them to flip them over, then kicking them away. Simultaneous two-player, and players can flip each other.

Getting started

  1. Insert a coin — the coin slot at the top left, or 5.
  2. Press 1 player start — the 1P button, or 1.

The multiplier only holds while each kick follows the last within about a second.

Strategy

  • Kick them in a chain. One at a time is 800 apiece; four inside a second is 6,400 for the fourth alone. The whole scoring system rewards flipping several before clearing any.
  • Flip first, kick later. A flipped enemy stays flipped for a few seconds. Turning over a crowd and then clearing it is how the chain is set up.
  • A flipped enemy rights itself angrier. Leave it too long and it returns faster than before.
  • The POW block is finite. Three uses per level, and it flips everything touching the floor — the fastest way to start a chain.

Arcade controls

Coin on 5, start on 1, and the six cabinet buttons on Z X C V A S. The arcade controls page covers the panel in full.
