Pitfall!

Activision, 1982 — designed by David Crane. The bestselling 2600 game after Pac-Man; the founding side-scrolling jungle platformer.

System help — the Atari 2600 controls

Pitfall Harry has 20 minutes to recover 32 treasures from a procedurally-generated jungle. 255 screens connected left and right, plus underground tunnel shortcuts. Avoid alligators, scorpions, snakes, rolling logs, tar pits, sand pits, quicksand. Vines swing across pits. Time bleeds with every screen.

Getting started

  1. Click game select (or press V) for variant.
  2. Click game reset (or press Enter) to start.
  3. Run right with the joystick; jump with Space.

Strategy

  • Vine-swing timing. Tap Space as the vine comes overhead, hold to swing further. Release at peak of arc to drop on the far edge.
  • Underground shortcut. Going underground covers 3 above-ground screens in one tunnel-screen. Use it to outpace the timer — but watch for scorpions and brick walls (which dead-end you).
  • Don't lose time. Falling into a pit/quicksand/tar costs you a life AND restarts on the same screen — wasted time. Treasure totals don't beat the timer alone.
  • Crocodile heads. Step gingerly on a closed croc snout — running can carry you into the next-open mouth. Stop-step-jump.
  • 32 treasure perfect run. 114,000 points clears the game. Pick a deterministic route — Pitfall's "random" jungle is actually a fixed seed.

Atari 2600 controls

Single-stick + button. game reset (or Enter) starts the run. The game ends when the timer hits 0 or you lose all three lives — whichever comes first.
