Apple · Apple I

The Woz Monitor

1976 — 256 bytes of ROM by Steve Wozniak, and the entire user interface of the first Apple.

System help — the Apple I controls

There is no operating system here and no BASIC until you load one. What the Apple I gives you is a backslash prompt and a monitor that does three things: show memory, change memory, and jump to an address. Woz wrote it in 256 bytes. Everything the machine did in 1976 was done through these few characters, and working that way for five minutes explains the next decade of home computing rather well.

Getting started

  1. The screen shows a \ prompt and a cursor.
  2. Type FF00 and press Enter to see the byte at that address.
  3. Type 0:A9 41 20 EF FF to write five bytes at address 0.
  4. Type 0R to run what you just wrote.
  5. For a language, load Integer BASIC from the menu and type E000R.

Keys that are not where you expect them

The monitor is the whole interface; these are its keys.

KeyboardAction
EnterSubmit the line. The monitor answers immediately
PauseReset the machine, which is how the real Apple I did it
Ctrl+CBreak out of a running BASIC program once one is loaded

What the monitor understands

TypeWhat it does
XXXXShow the byte at hex address XXXX
XXXX.YYYYShow the range XXXX to YYYY, eight bytes to a row
.YYYYCarry the previous range on up to YYYY
XXXX: DD DD DDWrite those byte values starting at XXXX
: DD DD DDCarry on writing after the last byte stored
XXXXRRun — jump to hex address XXXX. E000R enters Integer BASIC once it is loaded

Everything is hexadecimal and there is no error message worth the name: a line the monitor does not understand simply does nothing. That is not this emulator being unhelpful, it is 256 bytes of ROM having no room to be polite.

Tips

  • Addresses and values are hex. There is no decimal anywhere in the monitor.
  • R is the whole of ‘run’. There is no LIST, no SAVE, and no undo.
  • Integer BASIC is a separate load. The Apple I shipped with nothing; BASIC came on tape and went in at E000.
  • Nothing is kept. Reload the page and the memory is blank again.
