MAX BASIC

1982 — BASIC on a games console that was never sold with any, plugged in from a cartridge.

System help — the Commodore MAX Machine controls

The MAX Machine is the odd one out: a cut-down, cartridge-only Commodore released in 1982 and sold only in Japan. Its cartridge slot is compatible with the 64's, which is the family resemblance; whether it counts as the 64's predecessor is argued about and we will not settle it here. It had no BASIC of its own — switch a MAX on with nothing in the slot and there is nothing to talk to. BASIC arrived as a cartridge you bought separately, and that is what is loaded here. With 2K of RAM it is the most cramped BASIC on the site, which is rather the point.

Getting started

  1. BASIC is already in the slot, so you get a prompt and a cursor.
  2. PRINT 2+2, then Enter.
  3. 10 PRINT "HI", 20 GOTO 10, RUN.
  4. Scroll Lock is RUN/STOP.

There is very little memory here. Long programs will run out of room in a way they would not on a 64, and that is the machine rather than the emulator.

Tips

  • It is a calculator too. PRINT 2+2 and press Enter. No program required.
  • Line numbers decide the order, not the order you typed them. Number in tens so there is room to squeeze lines in later.
  • Editing is done on screen. Move the cursor up to a listed line, change it, press Enter on it. That re-enters the whole line.
  • Nothing is kept. SAVE works, and the result goes when the tab closes.
