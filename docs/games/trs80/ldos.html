LDOS 5.3.1

1991, MISOSYS — the operating system people bought because Tandy's was not good enough, still being updated a decade on.

System help — the Tandy TRS-80 Model III controls

LDOS is what a serious TRS-80 owner replaced TRSDOS with, and the version here is a late one — released in 1991, years after Tandy had moved on, and the last of the line. That it existed at all tells you something about the people who used it. It does everything TRSDOS does and rather more: job control files, a proper text editor, filters you can put between a program and the screen, and a HELP command that actually helps.

Getting started

  1. It boots to the LDOS prompt, and may ask for the date.
  2. Type HELP and press Enter — this disk carries its own help.
  3. DIR lists the disk; FREE shows what is left.
  4. BASIC for Disk BASIC, TED for the text editor. Esc is BREAK.

Keys that are not where you expect them

The Model III's own BREAK key is the one to know.

Tips

  • HELP is not decoration. LDOS shipped its documentation on the disk, which in 1991 was still unusual.
  • Filters are the clever bit. LDOS lets you put a filter between a program and a device — the ancestor of piping, on a machine with 48K.
  • TED is a real editor, not a line editor. After EDLIN on the DOS shelf it feels like the future.
  • Nothing is kept. Write to the disk freely; a reload puts it back.
