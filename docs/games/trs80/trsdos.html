Personal Computer · Tandy TRS-80 Model III

TRSDOS 1.3

1981, Tandy — the disk operating system the Model III shipped with, on its own boot disk.

System help — the Tandy TRS-80 Model III controls

Every other entry on this shelf is a game that loads and takes the machine over. This one hands you the machine: TRSDOS is what a Model III owner with a disk drive actually sat in front of, a command prompt with a library of built-in commands and a copy of Disk BASIC on the disk beside it. It is a business machine's operating system, and it reads like one.

Getting started

  1. It boots to the TRSDOS prompt. It may ask for the date first — press Enter to skip past it.
  2. Type LIB and press Enter. That lists the built-in commands.
  3. DIR shows what is on the disk, FREE how much room is left.
  4. BASIC puts you in Disk BASIC; Esc is BREAK if something runs away with itself.

Keys that are not where you expect them

The Model III's own BREAK key is the one to know.

The commands above were read off the disk image this page actually boots, rather than from a manual for some other build of TRSDOS. LIB remains the honest answer to “what can I type here”.

Tips

  • Start with LIB. It is the contemporary way of finding out what a TRS-80 disk can do, and it still is.
  • BUILD then DO is a batch file. Write a few commands into a file and run them as one.
  • Disk BASIC is a superset of the ROM BASIC. Typing BASIC gets you the disk commands on top of the language the cassette machines had.
  • Nothing is kept. You can format and write to this disk all you like; reload the page and it is back as it was.
