Codebreaker

A Mastermind-style game of logic and deduction, from David Busch's 25 Games for your TRS-80 Model 100 (TAB Books, 1984).

System help — the TRS-80 Model 100 controls

The computer picks a secret four-letter code; you have eight guesses to crack it. After each guess it grades you — how many letters are right and in the right place, how many are right but misplaced — and you reason your way in from there.

Getting started

  1. The title appears and asks Instructions? — press Y to read them or N to start.
  2. At Guess:, type a four-letter guess using only the letters A B C D E. The code may repeat letters and leave some out — AAAA, CDDE and EBCB are all valid.
  3. Read the clue, deduce, and guess again — you get eight tries.

Controls

Letters register the moment you press them — no ENTER, and no need to hold SHIFT (lower case is accepted and shifted up for you):

KeyboardAction
A–EEnter a letter of your four-letter guess
Y / NAnswer the Instructions? and Play again? prompts

Reading the clue

After each full four-letter guess a clue appears — the marks don't line up with positions, they just tally how well you did:

ClueMeaning
C (a solid block)One letter is correct and in the right position
POne letter is in the code but in the wrong position
----None of your letters appear in the code at all

So CCCC means you've cracked it. A guess of AABB against the code AABB scores four Cs — the win.

Winning

Break the code in eight guesses or fewer and it tells you how many tries it took. Run out of guesses and it reveals the answer — then offers you another round.
