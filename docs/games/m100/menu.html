The Startup Menu

1983 — the first properly portable computer, and the last thing Bill Gates wrote code for himself.

System help — the Tandy TRS-80 Model 100 controls

The Model 100 does not boot to a prompt. It boots to a menu of the programs living in its ROM, because that is what a machine with a built-in modem and eight lines of screen was for: journalists filed copy from it for a decade. Everything here is instant — there is no loading, the applications are already in ROM, and the machine remembers your documents when you switch it off.

Getting started

  1. The menu lists the ROM applications with the cursor on one of them.
  2. Move the cursor with the arrow keys and press Enter to run one.
  3. BASIC gives you a BASIC prompt; TEXT is the word processor.
  4. F8 comes back to this menu from inside an application.

Keys that are not where you expect them

The function keys along the bottom of the screen change with whatever you are in; the labels are on screen at all times.

KeyboardAction
Arrow keysMove the selection on the menu
EnterRun the selected application
F8Return to this menu, saving as it goes
F1–F7Whatever the current application says they are, on the bottom line

What is on the menu

TypeWhat it does
BASICMicrosoft BASIC, at a prompt
TEXTThe text editor. F1 finds, F7 selects, F5 and F6 copy and cut
TELCOMThe terminal program, for the built-in modem
ADDRSSThe address book — a text file the machine searches for you
SCHEDLThe diary, same idea
Files below the lineDocuments and programs in memory. Select one to open it

ADDRSS and SCHEDL are not databases. They search a plain text file for a string, which is why the format is whatever you decide it is.

Tips

  • There is no loading. Everything on the menu is in ROM and starts the instant you press Enter.
  • TEXT saves as you leave — F8 stores the document and returns here.
  • The cassette options do nothing in the browser. There is no tape deck to talk to.
  • Nothing is kept once the tab closes.
