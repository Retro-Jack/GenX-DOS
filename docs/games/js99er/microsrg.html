Microsurgeon

Imagic (Mark Klein), 1982 — Solid State Software cart. Pilot a microscopic surgical probe through a patient's body, treating illnesses across 14 organs. A genre-of-one game in 1982 — part shooter, part diagnostic puzzle, all body-horror educational content.

The patient is a cross-section anatomical figure; arrows mark organs that need treatment (cancer, blood clots, tapeworm, plaque, etc.). Pilot the probe through the bloodstream — actual veins/arteries network — to reach each organ. Each illness has a specific treatment: ultrasonics, antibiotics, or aspirin. Run out of energy before clearing the diagnoses, the patient dies.

Getting started

  1. Press 2 at the TI title.
  2. Select skill 1 (easier — fewer simultaneous diseases) up to 4.

Controls

KeyAction
↑ ↓ ← →Navigate the probe
Space + a directionFire the selected treatment in that direction

7 / 8Probe speed — slow / fast

Strategy

  • Read the on-screen diagnosis. The status panel names the illness — each requires a specific tool. Don't waste shots; wrong-tool shots cost energy.
  • Bloodstream is a one-way network. Arteries flow heart→organs, veins return — plan routes via the heart.
  • Time matters. The patient deteriorates while you navigate; the closer to death they get the harder simple shots become.
  • 1982 educational genre. Microsurgeon is sometimes lumped with edutainment; the anatomical map is accurate enough to use as a (very stylised) circulatory-system tutor.
