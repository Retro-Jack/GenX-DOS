TI BASIC

1981 — the BASIC in the TI-99/4A's ROM, reached through the title screen.

System help — the Texas Instruments TI-99/4A controls

The TI-99/4A does almost everything through one keyword. Graphics, sound, the keyboard, the sprites — all of it arrives as CALL followed by a name, because Texas Instruments built the machine's extras as subroutines rather than as language. It makes for programs that read like instructions to somebody else, and it is the reason TI BASIC looks unlike any other on this site.

Getting started

  1. You land on the TI title screen first.
  2. Press 1 or Enter for TI BASIC.
  3. The > prompt takes commands. Try PRINT 2+2.
  4. CALL CLEAR clears the screen — note that it is a CALL, not a command.

Keys that are not where you expect them

The 4A's own control keys live behind FCTN on the real machine; this emulator maps them to PC modifiers so typing stays natural.

KeyboardAction
EnterENTER
1 at the title screenChoose TI BASIC
Ctrl+CBreak out of a running program

What you can type

TypeWhat it does
LISTShow the program
RUNStart it
NEWThrow it away
CALL CLEARClear the screen
CALL SCREEN(n)Set the screen colour
CALL COLORColour a character set
CALL HCHAR / CALL VCHARRepeat a character across or down the screen
CALL SOUNDDuration, then frequency and volume — up to three tones and a noise
CALL KEYRead the keyboard without waiting
PRINT INPUTThe usual
FOR … NEXT, IF … THEN, GOSUBAnd the rest of it

One oddity worth knowing before it confuses you: in CALL SOUND the volume runs from 0 as loudest to 30 as quietest. Everywhere else in computing that number goes the other way.

Tips

  • Nearly everything is a CALL. If you are looking for a command to do something to the screen or the speaker, it is a CALL.
  • CALL SOUND(1000,440,0) plays a concert A for a second at full volume.
  • TI BASIC is slow, and the machine's owners knew it — the faster route was Extended BASIC on a cartridge.
  • Nothing is kept once the tab closes.
