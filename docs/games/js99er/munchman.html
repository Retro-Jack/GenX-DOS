Munch Man

Texas Instruments (Jim Dramis), 1982 — Solid State Software cart. TI's clean-room Pac-Man alternative, designed to dodge an Atari trademark suit. Same maze-chase premise but Munch Man leaves a trail behind him — fill every empty corridor of the maze instead of eating dots.

Maze-chase grid: hostile "Hoonos" (ghost analogue) patrol corridors. Munch Man walks every corridor leaving a chain behind him; the maze clears when every empty tile has been traced. Power-up "energy" segments turn the Hoonos vulnerable for a few seconds, just like Pac-Man's power pellets.

Getting started

  1. Press 2 at the TI title.
  2. Select 1 or 2 players, then skill 1-3.

Controls

KeyAction
↑ ↓ ← →Steer Munch Man through corridors
Any keyPause; press any key again to resume

Strategy

  • Plan the trail, not the dots. You're filling every empty tile — corridors you've already visited become permanently chained. Pre-plan a route that hits every corner without backtracking past a Hoono.
  • Energy clears chasers. The energiser-equivalents at corners are limited; save one for when you're cornered.
  • Hoonos have personality. Like Pac-Man's ghosts, each has a different chase pattern — observe in attract mode.
  • Distinct from Pac-Man. If you're expecting dot-eating geometry, the trail mechanic changes the math: cul-de-sacs cost double (you trace in, then trace out, never reaching new tiles on the return).
