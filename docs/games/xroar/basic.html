Personal Computer · Tandy Color Computer

Color BASIC

1980 — Microsoft BASIC in 8K of ROM, on the machine everybody called the CoCo.

System help — the Tandy Color Computer controls

This is the plain Color BASIC, and the thing to know about it is what is missing: it has no graphics commands at all. The high-resolution screen, PMODE, LINE, CIRCLE, PAINT and DRAW all belong to Extended Color BASIC, which was a different ROM you paid more for. What this one gives you is text, a 64×32 grid of coloured blocks, and sound — and a great deal of CoCo software was written inside exactly those limits.

Getting started

  1. The machine comes up with OK and a cursor.
  2. PRINT 2+2, then Enter.
  3. CLS 3 clears the screen to a colour.
  4. SET(10,10,4) puts a coloured block on the screen.
  5. Break stops a running program.

Keys that are not where you expect them

Colour here is blocks on the text screen, not pixels — that is Color BASIC rather than a limitation of this emulator.

What you can type

CLS nClear the screen to one of nine colours
PRINT@ n,Print at a screen position
SET(x,y,c)Put a coloured block on the 64×32 grid
RESET(x,y)Take one away
POINT(x,y)Ask what colour a block is
SOUND p,dA pitch and a duration
FOR … NEXT, IF … THEN, GOSUBThe usual
PEEK POKE EXECMemory, and machine code
CSAVE CLOADTape, if there were one

If you try PMODE or CIRCLE here you will get an error, and that is correct: those came with Extended Color BASIC, a separate ROM. This is the 1980 machine as it shipped.

Tips

  • SET and RESET are the graphics. A 64×32 grid of blocks in nine colours, and that is your lot.
  • CLS with a number gives you a whole screen of one colour, which is the fastest way to see the palette.
  • The CoCo's real trick was artefact colour — abusing the video signal to get colours the hardware does not officially have.
