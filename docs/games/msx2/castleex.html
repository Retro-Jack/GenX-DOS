Castle Excellent

ASCII Corp, 1986 — flip-screen castle puzzle-platformer; sequel to "The Castle" (1985). Rescue Princess Margaret from the wizard's castle by working out which of 100 numbered rooms unlocks the next. The MSX2 version cleaned up the palette and used the V9938 to give each room a distinct hue.

System help — the MSX2 controls

Each room is a single screen; coloured doors are unlocked by collecting the matching key elsewhere in the castle. The whole game is a giant lockbox — door A needs key A from a room behind door C which needs key C from a room behind door B, etc. Touch a monster = die back to the last fountain.

Getting started

  1. Click the game area to enable sound and controls.
  2. Press Space at the title to begin in the entrance hall.

Controls

KeyAction
← / →Walk left / right
↑ / ↓Climb ladders
SpaceJump (forward jump with run-up)

Strategy

  • Map every door. The game does not provide a map; pencil one early. Note the colour of each locked door and the room number beside it.
  • Fountains are save points. Touch a fountain to update the respawn point — always tag a fountain before any tricky platforming run.
  • Some platforms are reached only on the bounce. Beware breakable blocks: drop through them once, the block stays gone forever.
  • Distinct from Maze of Galious. Konami's similar-vibe MSX adventure is a different game; Castle Excellent is ASCII Corp's, and the puzzle logic is tighter and more linear.
