Snapper

Acornsoft, 1983 — Jonathan Griffiths. Acornsoft's Pac-Man — Electron port runs in Mode 5 with the same maze layout as the BBC version, slightly slower scroll due to ULA contention.

Guide the Snapper around a maze, eating dots while the four ghosts chase you. Eat the corner power-pills to turn them edible for a brief window. Clear every dot to move on; each cleared maze speeds up and shortens the power-pill window.

Getting started

  1. Tape auto-loads. Press Space at the title to start.
  2. Steer towards dots. The first maze is forgiving; later mazes have Sour Faces leaving the pen sooner.
  3. Save power-pills for when cornered — gain more by eating multiple ghosts on one pill.

Controls

This game supports a USB gamepad — the D-pad or left stick steers Snapper, and any face button starts a game.

On a PC keyboard the Electron *: key lands on the apostrophe — this emulator maps it to ', so it's listed as ' below.

Strategy

  • Chain the ghosts. Herd all four near one power-pill before triggering; 3000 bonus on a clean four-chain.
  • Tunnels are escape valves. The wrap-around exits slow ghosts more than they slow you — use under pressure.
  • Don't backtrack for stray dots. Plan a single loop around the maze; leftover dots eat the maze-clear bonus.
