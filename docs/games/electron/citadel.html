Citadel

Superior Software, 1985 — Michael Jakobsen. Electron port of the BBC arcade-adventure-platformer; ~100 interconnected rooms.

System help — the Acorn Electron controls

Find the five hidden crystals scattered across the maze and return them to open the way into the citadel. Rooms hold keys, food, scrolls, and helpful objects — alongside creatures that drain energy on contact. Match the right object to the right obstacle; the puzzle is half platforming, half adventure inventory.

Getting started

  1. The snapshot boots into Citadel's room slideshow (an attract demo that cycles through rooms) — press Return to start playing.
  2. You start outside the castle. Walk through the door on the right and collect everything you can pick up.
  3. You carry one object at a time; drop the current item by walking over a new one — choose carefully.

Controls

This game supports a USB gamepad — the D-pad or left stick moves, A jumps and B casts a spell / uses an object. A starts play from the attract demo.

The snapshot boots with Citadel's default key layout (below). The Electron's * and ? keys aren't where a PC keyboard puts them — this emulator maps the *: key to your PC apostrophe ' and the / ? key to /, so press those for up/down.

Strategy

  • Map as you go. Citadel has no in-game map — pen-and-paper grid is the original walkthrough.
  • Energy is your only timer. No clock; monster hits chip the bar. Always know where the nearest apple is.
  • Object swaps cost progress. Drop the key and walk away, the room's enemies usually take it back. Carry it to the door.
  • Sealed rooms are clues. If you've cleared everywhere reachable and a room remains shut, you're missing an object — not a jump.
