Personal Computer · Acorn Electron

BBC BASIC

1983 — Acorn's cut-down BBC for the home. The same language, on a machine with rather less underneath it.

System help — the Acorn Electron controls

The Electron carries BBC BASIC II in ROM, the same language the BBC Micro made its name with: named procedures and functions, REPEAT…UNTIL and WHILE…ENDWHILE, local variables, a real ELSE, and a 6502 assembler built into the language. What Acorn cut to reach the price was the hardware around it — one chip doing the work of several, no teletext, no disc interface, no second processor — so the language is the Model B's and the machine under it is not.

Getting started

  1. The machine comes up saying Acorn Electron, then BASIC, then gives you a > prompt.
  2. PRINT 2+2, then Enter.
  3. MODE 1 changes the screen. The Electron has modes 0 to 6.
  4. Esc stops a running program.
  5. F12 is BREAK, which resets the machine — the same as reaching for the real one's BREAK key.

Keys that are not where you expect them

The Electron's keyboard is read by position, so a few of its keys land somewhere else on a PC one. The orange FUNC key is the one to know: it is how the machine reaches the function keys it has no room for.

Tips

  • MODE 7 is not teletext here. Ask for it and the machine quietly gives you MODE 6 instead: the Electron has no teletext chip and its operating system substitutes rather than refuses. You can watch it happen — type MODE 7 and then PRINT HIMEM and you get 24576, the MODE 6 figure, where a BBC Micro would answer 31744. Plenty of BBC listings open with MODE 7, and this is why they look wrong here.
  • Procedures, not GOSUB. DEF PROCname and call it as PROCname. It is why BBC BASIC programs are readable.
  • The assembler is part of the language. Square brackets, 6502 mnemonics, and BASIC variables as labels.
  • There is no disc, so there is nothing to *CAT. The Electron saved to cassette, and the games on this site are memory snapshots the launcher drops straight into RAM rather than tapes it plays in.
