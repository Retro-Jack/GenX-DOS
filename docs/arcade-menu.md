# GenX-DOS — Arcade menu structure

**ARCADE -> 10 manufacturers -> 10 games each = 100 games.**

Lives at `C:\SYSTEMS\ARCADE\<MAKER>\GAMES`, the same shape as `CONSOLE\NES\GAMES`.
ARCADE is row 4 of the EMULATOR LAUNCHER; the wiki moved to row 5.

Every year and manufacturer is taken from the emulator's own metadata rather than from memory.
**Makers are listed alphabetically**, matching the CONSOLE menu — a menu ordered by
someone's private ranking isn't self-evident to a player. Games run **year ascending**
within each maker, alphabetical within a year.

The menus show title and year only. Each row's launcher is still typeable at the prompt
(`ARKANOID`), and every launcher is named after its romset, as the site's other launchers
are. All 100 fit 8.3 and are unique across the section.

Verified: no title is a sequel or spinoff, every game's recorded manufacturer matches the maker
it is filed under, and every year falls inside 1970-1989.

## Judgement calls

- **Galaga and Ms. Pac-Man kept.** Technically sequels, universally treated as their own games — the carve-out in your rule.
- **Donkey Kong Jr. dropped.** A direct numbered sequel that reads as one, unlike the two above.
- **Pac-Man under Namco, Ms. Pac-Man under Midway.** Different games by different makers, which is the point of filing by maker.
- **Taito's Space Invaders uses `SITV`**, Taito's own 1978 release, not the Midway US set the rest of the world played. MAME files it as a clone of the Midway parent, so the build may need the parent zip alongside it — to be tested.
- **Excluded as sequels:** Asteroids Deluxe, Millipede, Super Breakout, Gauntlet II, Super Zaxxon, 1943, Ghouls'n Ghosts, Stargate, Joust 2, Time Pilot '84, Dig Dug II, Pole Position II, Super Punch-Out!!, Donkey Kong 3, R-Type II, Rolling Thunder 2, Galaga '88, Fantasy Zone 2.
- **Excluded as not arcade-originated:** Lode Runner, Spelunker, Choplifter, Pitfall II, every PlayChoice-10 / Vs. System / MegaTech / MegaPlay cabinet, and Midway's Gun Fight (a conversion of Taito's Western Gun).

## Build notes

- **All 100 romsets exist in this core and can be built from the local library.** Nothing needs sourcing online.
- **93 verify byte-exact as they stand.** Seven — Galaga, Dig Dug, Pole Position, Bubble Bobble, Space Fever, Sheriff, HeliFire — hold the correct ROM *content* under different filenames, so they are rebuilt by CRC rather than re-sourced. Pole Position has already been done this way.
- **97 of 100 have marquee artwork** in the libretro set. The three gaps are all Irem: Traverse USA, Image Fight, Ninja Spirit.
- Cabinet orientation is already read per game from the emulator's metadata, so both cabinets keep working with no extra effort.

## Errors caught while compiling this

Automated title-matching produced **eleven wrong picks** out of 100. None would have been obvious in a finished list, which is why each entry was checked against the metadata:

| matched | what it actually was |
|---|---|
| `mp_gaxe2` | Golden Axe II (1993) — a MegaPlay Mega Drive cabinet |
| `mp_shnb3` | Shinobi III (1993) — likewise |
| `puckpkmn` | "Puckman Pockimon" — a 2000 bootleg |
| `fantzn2` | Fantasy Zone 2 — a sequel |
| `galaga88` | Galaga '88 — a sequel |
| `rthun2` | Rolling Thunder 2 (1990) — sequel, and out of period |
| `gaunt2` | Gauntlet II — a sequel |
| `rtype2` | R-Type II — a sequel |
| `dkong3` | Donkey Kong 3 — a sequel, sitting where **Donkey Kong itself** should have been |
| `minferno` | Inferno by **Meadows**, not Williams |
| `commsega` | Commando by **Sega**, not Capcom |

The `dkong3` one is worth dwelling on: it meant **Donkey Kong was missing from Nintendo's ten** — the single most important game that maker produced — and the list still looked complete.
